Также в 1.7.0: Night Shift может пробовать задачу несколько раз и оставлять лучшую попытку (/night add --best-of N), одна машина может запускать несколько мостов Signal, а клиент выбирает между двумя узлами в одной сети, не теряя знакомый. Примечания к релизу и загрузки.

Установка

$ curl -fsSL https://github.com/dreamference/mightling/releases/latest/download/install.sh | bash
$ ling-admin server start      # один раз скачивает модель (~20 ГБ), затем запускает её
$ cd ~/your-project && ling    # вот и всё

Работает на NVIDIA DGX Spark и на любой машине с GB10. Скрипт проверяет каждую загрузку по контрольным суммам релиза и показывает каждую команду sudo перед запуском. Сначала прочитайте его, если хотите.

Клиенты для Mac и Linux

Ваши остальные компьютеры используют модель GB10 по локальной сети. На Mac или другой Linux-машине та же команда выше ставит клиент ling; он сам находит GB10.

Начиная с 1.7.2 он также кладёт десктопное приложение в «Программы» на Mac, готовое к запуску (--no-app это отключает).

Клиент для Windows превью

> irm https://github.com/dreamference/mightling/releases/latest/download/install.ps1 | iex

В PowerShell. Установка идёт без прав администратора (с 1.7.2 и для десктопного приложения), после чего Windows один раз спросит о настройке песочницы агента. Пока без подписи, поэтому Smart App Control должен быть выключен. Прочитать скрипт.

Другие способы установки

На странице релиза есть также dmg для Mac (Mightling-<version>-arm64-preview.dmg, для Intel x64) и установщик для Windows (Mightling-Setup-<version>-x64.exe, либо arm64). Это неподписанные превью: скачанные через браузер, они блокируются при первом запуске. Сначала сверьте каждый файл с подписанным файлом SHA256SUMS релиза.

  • macOS 15 и новее: перетащите Mightling в «Программы» и один раз откройте, затем «Системные настройки» › «Конфиденциальность и безопасность» › Всё равно открыть. В macOS 14 и старше: щёлкните по приложению с зажатым Control › «Открыть».
  • Windows: SmartScreen › Подробнее › Выполнить в любом случае. Smart App Control должен быть выключен.

Попробуйте сначала это

Или поставьте работу в очередь на ночь командой /night add <task>: Mightling разбирает очередь, пока вы спите, каждую задачу в своей git-ветке, а вы просматриваете ветки за утренним кофе.

$ ling "explain this repository to me like I'm new on the team"
# reads the code index (ling-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ling "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ling-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

Work — полноценный верстак для агентских сессий: поле ввода с файлами, навыками и командами, панель ревью, где можно добавлять в индекс, откатывать и коммитить, worktree, вкладки терминала, а также дерево файлов и вкладки файлов рядом с потоком. На ваших остальных компьютерах оно служит клиентом вашего GB10, который находит в локальной сети.

Ваш код никогда не покидает ваш стол — и это можно доказать

Облачные кодинг-агенты отправляют ваш исходный код на чужие серверы. Mightling не отправляет его никуда: модель работает на вашем GB10, и ничто в Mightling не отправляет данные «домой». Ни аналитики использования, ни метрик, ни входа в аккаунт, ни «анонимных» отчётов о сбоях. Поэтому его можно использовать для кода, который нельзя выгружать: клиентских проектов, регулируемых данных, неизданных продуктов.

Одна команда запускает настоящую сессию Mightling под strace и перечисляет все сетевые соединения, которые она открыла:

$ ling-admin audit egress
✔ Egress audit: pass
Network destinations:
   127.0.0.1:8000     29x  model server
   127.0.0.1:8767      1x  Gmail search service
DNS queries: none
Networked git commands: none

Всё осталось на 127.0.0.1. Ни одного DNS-запроса.

Нужна жёсткая гарантия?

Введите /airgapped on, и каждая команда, которую запускает агент, получает от ядра Linux пустое сетевое пространство имён. Это не вежливая просьба к модели: просто нет сети, до которой можно достучаться. Full Access, который обошёл бы песочницу, при этом отклоняется.

Что может уйти и когда

Только то, что запрашиваете вы или агент: веб-поиск (через приватный SearXNG на вашей машине), загрузка страницы, запрос только на чтение к подключённому аккаунту Google или проверка обновлений. При /airgapped on — ничего из этого.

SWE-bench Verified, измерено на одном DGX Spark

2026-10-08 агент Mightling 1.5.1 с Qwen3.8-27B решил 68 из 100 задач SWE-bench Verified на одном DGX Spark, офлайн: фиксированная выборка из 100 задач, одна попытка на задачу, режим по умолчанию. В пересчёте на все 500 задач это примерно ≈69% по оценке (95-процентный интервал 63,9–73,4%). Это наше собственное измерение, на нашей машине и на подмножестве, а не запись в рейтинге.

Читайте это как сравнение компаний, а не рейтинг. На тех же 100 задачах Mightling решил столько же, сколько Qwen3-Coder-480B и GLM-4.6, модели, во много раз крупнее его, но в каждой строке свой агент, своё железо, а в строках рейтинга ещё и официальные тестовые образы x86, тогда как у нас работали образы сообщества для arm64. В режиме refine первая сессия изучает задачу, ничего не меняя, а новая сессия её выполняет: он решил на одну задачу больше, чем режим по умолчанию (69 против 68, причём каждый вариант выигрывал задачи, которые проигрывал другой), затратив примерно в 2,2 раза больше времени на задачу, поэтому остаётся опциональным (ling --refine).

Как оценивается ≈69%

100 задач — это пятая часть Verified, поэтому цифра для полного набора является оценкой. Однопараметрическая модель Раша (item response) подгоняется по результатам по каждой задаче всех 175 публичных заявок на Verified: у каждой задачи есть сложность, у каждой системы способность. Способность Mightling — та, которая объясняет 68 решённых из этих 100 задач; ≈69% — ожидаемый результат этой способности на всех 500 (простая регрессия по опубликованным результатам согласуется с точностью до пункта). Для проверки каждая публичная заявка была оценена только на этих 100 задачах, а её общий результат предсказан тем же способом: ошибка составила 2,4 пункта (RMSE), а интервал выше — это ±1,96 от неё. Каждое число в таблице воспроизводит scripts/swe_bench_compare.py по публичным данным по каждой задаче из SWE-bench/experiments.

100 задач распределены по репозиториям Verified пропорционально полному набору среди задач, тестовая среда которых запускается и проходит проверку на arm64 (эталонный патч проходит, пустое изменение — нет). Опубликованные системы набирают на этих 100 задачах на 1,0–1,5 пункта меньше, чем на всех 500, так что выборка не из лёгких. Это не запись в рейтинге: их оценивает команда SWE-bench на собственной инфраструктуре.

  11. Anthropic публикует SWE-bench Verified для своих моделей Claude, запущенных в собственной простой обвязке (инструмент bash и инструмент редактирования), а не для продукта Claude Code. Источники: Claude Code, методика Anthropic для SWE-bench.
  12. Cursor публикует результаты на собственном бенчмарке Cursor Bench, а не на SWE-bench Verified. Источник: блог Cursor, Composer.

Все цифры рейтинга: swebench.com и репозиторий SWE-bench/experiments; «те же 100 задач» — это опубликованные результаты каждой заявки по задачам, ограниченные теми, что прогонял Mightling.

FAQ

Нужен ли мне GB10?

Да, чтобы запускать модель. Остальные ваши компьютеры используют его как клиенты: Linux (Arm или x86) и macOS с той же командой установки, Windows (Arm или x86, превью) со строкой PowerShell.

Я установил Puffin. Это он?

Да: в 1.5 Puffin переименовали в Mightling. Один раз выполните puffin update, затем в последний раз puffin. Он перенесёт ваши сессии, настройки и ссылки, и дальше команда будет ling.

Это правда бесплатно?

Да. Mightling — открытый исходный код под AGPL, а веса модели бесплатны. Единственные текущие расходы — электричество.

Что нужно, кроме самой машины?

Поставляемая с ней ОС (DGX OS 7 или Ubuntu 24.04, где её предлагает вендор), Docker с NVIDIA Container Toolkit, Python 3 и Git. На обычной Ubuntu ling-admin host check подскажет, чего не хватает.

Уходит ли что-нибудь в интернет?

Только то, что запрашиваете вы или агент, например веб-поиск через SearXNG на вашей машине, и загрузки при первом запуске. /airgapped on отключает всё это.

Какую модель он запускает?

Qwen3.8-27B в 4-битном формате NVIDIA NVFP4, обслуживается через SGLang с драфтером DFlash2, выбрана и настроена под GB10. Около 20 ГБ весов; пока она работает, около 38 ГБ памяти машины остаются свободными.

Храните свой код у себя на столе

Если вы считаете, что код должен оставаться на столе, за которым его написали, поставьте репозиторию звезду: так другие владельцы GB10 находят Mightling.
