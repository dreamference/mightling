v1.7.0 →

Ещё в 1.7.0: Night Shift может пробовать одну задачу несколько раз и оставлять лучшую попытку (/night add --best-of N). Одна машина может запускать несколько мостов Signal. А компьютер, который видит в одной сети два GB10, может выбирать между ними и не забывает тот, который уже знает. Примечания к релизу и загрузки.

Установка

$ curl -fsSL https://github.com/dreamference/mightling/releases/latest/download/install.sh | bash
$ ling-admin server start      # один раз скачивает модель (~20 ГБ), затем запускает её
$ cd ~/your-project && ling    # вот и всё

Это работает на NVIDIA DGX Spark и на любой другой машине с GB10. Скрипт сверяет каждую загрузку с контрольными суммами релиза и показывает каждую команду sudo перед тем, как её выполнить. Вы можете сначала прочитать скрипт.

Клиенты для Mac и Linux

Ваши остальные компьютеры берут модель с GB10 по домашней или офисной сети. На Mac или другой машине с Linux та же команда ставит ling — ту часть, в которую вы вводите текст. Она сама находит GB10.

Начиная с 1.7.2 она также кладёт приложение для компьютера в «Программы» на Mac, готовое к запуску. Добавьте --no-app, если оно вам не нужно.

Клиент для Windows превью

> irm https://github.com/dreamference/mightling/releases/latest/download/install.ps1 | iex

Введите это в PowerShell. Права администратора не нужны (с 1.7.2 это верно и для приложения для компьютера). Затем Windows один раз попросит создать изолированное место, где помощник запускает команды. Установщик пока не подписан, поэтому Smart App Control должен быть выключен. Прочитать скрипт.

Другие способы установки

На странице релиза есть ещё образ диска для Mac (Mightling-<version>-arm64-preview.dmg, или x64 для Intel) и установщик для Windows (Mightling-Setup-<version>-x64.exe, или arm64). Это неподписанные предварительные сборки, поэтому, когда вы скачиваете их в браузере, система в первый раз их останавливает. Прежде чем открыть файл, сверьте его с подписанным файлом SHA256SUMS из релиза.

  • macOS 15 и новее: перетащите Mightling в «Программы» и один раз откройте. Затем зайдите в «Системные настройки» › «Конфиденциальность и безопасность» и нажмите Всё равно открыть. В macOS 14 и старше щёлкните по приложению с нажатой клавишей Control и выберите «Открыть».
  • Windows: SmartScreen › Подробнее › Выполнить в любом случае. Smart App Control должен быть выключен.

Попробуйте сначала это

Или оставьте работу на ночь командой /night add <task>. Mightling проходит по списку, пока вы спите, каждая задача в своей ветке git, а утром вы просматриваете ветки.

$ ling "explain this repository to me like I'm new on the team"
# reads the code index (ling-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ling "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ling-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

Что вы получаете

Приложение для компьютера в 1.7.0 собирает оба способа работы с Mightling в одном окне: Ask, где вы задаёте вопросы, и Work, где помощник правит ваш код. В Work есть поле для ввода задач (можно прикреплять файлы, навыки и команды), панель, где можно просмотреть изменения, прежде чем оставить их или отменить, отдельные рабочие копии кода (worktree), вкладки терминала и дерево файлов рядом с разговором. На ваших остальных компьютерах приложение работает с вашим GB10, который находит в вашей сети.

ling · ling-code · ling-docs

Он читает ваш проект, запускает команды и тесты, правит код и спрашивает вас, прежде чем сделать что-то рискованное.

Потом откройте его из меню приложений или введите ling app. Подробнее.

Ваш код остаётся у вас на столе, и вы можете это проверить

Облачный помощник по программированию отправляет ваш исходный код на компьютеры, которые принадлежат кому-то другому. Mightling не отправляет его никуда. Модель работает на вашем GB10, и ничто в Mightling не звонит домой: ни счётчиков использования, ни измерений, ни входа в аккаунт, ни даже «анонимных» отчётов о сбоях. Поэтому им можно пользоваться с кодом, который нельзя выгружать: работой клиента, защищёнными данными или ещё не вышедшим продуктом.

Одна команда запускает настоящую сессию Mightling под strace — инструментом, который следит за каждым вызовом программы, — а потом выводит каждое сетевое соединение, которое сессия открыла:

$ ling-admin audit egress
✔ Egress audit: pass
Network destinations:
   127.0.0.1:8000     29x  model server
   127.0.0.1:8767      1x  Gmail search service
DNS queries: none
Networked git commands: none

Всё осталось на 127.0.0.1, то есть машина говорила сама с собой. Не было ни одного DNS-запроса (DNS-запрос — это вопрос к интернету, какой адрес у имени).

Нужна твёрдая гарантия?

Введите /airgapped on. Каждая команда, которую запускает помощник, получает от ядра Linux пустую сеть. Это не вежливая просьба к модели. Просто нет сети, до которой можно дотянуться. При этом Full Access, который обошёл бы песочницу, отклоняется.

Что может уйти и когда

Только то, о чём просите вы или помощник: веб-поиск (через частный SearXNG на вашей машине, хотя сам поиск всё же уходит в интернет), загрузка веб-страницы, запрос только на чтение к подключённому аккаунту Google или проверка обновлений. При /airgapped on ничего из этого не происходит.

Это скорости для одной задачи за раз на GB10. Модель использует приём, который называется спекулятивным декодированием: маленький помощник угадывает несколько слов вперёд, а большая модель проверяет все догадки за один раз. «Работа с кодом» измерена на настоящих сессиях помощника. Написание кода, JSON и текста измерено на выводе такого вида. Последняя строка — сколько текста она может держать в уме сразу: 262K токенов, это несколько сотен страниц. Запускайте хоть четырёх помощников одновременно. Нет ни квоты, ни «подождите».

✨ Почти нечего настраивать

SWE-bench Verified, измерено на одном DGX Spark

SWE-bench Verified — это набор из 500 настоящих задач, взятых из программ с открытым кодом. В каждой помощник должен изменить код так, чтобы тесты проходили. 2026-10-08 мы дали 100 из них Mightling 1.5.1 с моделью Qwen3.8-27B на одном DGX Spark без интернета. На каждую была одна попытка, в режиме по умолчанию, и он решил 68 из 100. Если перенести это на все 500, получится примерно 69%, плюс-минус несколько пунктов (95-процентный интервал — от 63,9 до 73,4%). Мы измерили это сами, на своей машине, на части задач. Это не запись в официальном рейтинге.

Читайте эту таблицу как способ увидеть, кто рядом, а не как рейтинг. На тех же 100 задачах Mightling решил столько же, сколько Qwen3-Coder-480B и GLM-4.6, модели во много раз больше. Но в каждой строке своя программа-помощник и своё железо, а строки рейтинга использовали официальные тестовые образы для компьютеров x86, тогда как наши работали на образах сообщества для arm64. Есть и второй режим, он называется refine. Первая сессия изучает задачу и ничего не меняет, потом новая сессия делает работу. Он решил на одну задачу больше, чем режим по умолчанию (69 против 68, и каждый режим решил несколько задач, которые пропустил другой), и тратил примерно в 2,2 раза больше времени на задачу. Поэтому он выключен, пока вы не попросите его командой ling --refine.

Как мы оцениваем эти 69%

100 задач — это пятая часть Verified, так что число для всех 500 — оценка. Вот как мы её получили. Берём результаты всех 175 публичных решений Verified, задача за задачей. Каждой задаче даём сложность, а каждой системе — способность, по однопараметрической модели ответов на задания (модель Раша). Способность Mightling — та, при которой решаются 68 из этих 100 задач, и около 69% — то, что такая способность даст на всех 500. Простая регрессия по опубликованным результатам согласуется с этим в пределах одного пункта. Мы также проверили метод на других: для каждого публичного решения мы взяли только его результат на этих 100 задачах и предсказали его результат на всех 500. Ошибка составила 2,4 пункта (RMSE), а интервал выше — это 1,96 такой ошибки в каждую сторону. Каждое число в таблице можно воспроизвести скриптом scripts/swe_bench_compare.py по публичным данным по задачам в SWE-bench/experiments.

Мы распределили 100 задач по программам из Verified в тех же пропорциях, что и в полном наборе. Брали их из задач, у которых тестовая среда работает и подтверждается на arm64 (правильное исправление проходит, а отсутствие исправления не проходит). Опубликованные системы набирают на этих 100 задачах на 1,0–1,5 пункта меньше, чем на всех 500, так что выборка не лёгкая. И всё же это не запись в рейтинге, потому что команда SWE-bench проверяет такие записи на своих машинах.

  1. Mightling: 100 задач, по одной попытке; один DGX Spark (GB10, 128 ГБ), модель работает на машине, без облака; режим по умолчанию измерен 2026-10-08, режим refine — 2026-10-09. Оценка использует данные по задачам из SWE-bench experiments.
  2. 500 задач, одна попытка; железо не указано. Источник: experiments, 20250805_openhands-Qwen3-Coder-480B-A35B-Instruct. Та же модель с mini-SWE-agent: 57/100, 55,4%.
  3. 500 задач, одна попытка, агент не раскрыт; железо не указано. Источник: experiments, 20250930_zai_glm4-6.
  4. 500 задач, одна попытка; железо не указано. Источник: experiments, 20260217_mini-v2.0.0_kimi-k2-5-high.
  5. 500 задач, одна попытка; железо не указано. Источник: experiments, 20260217_mini-v2.0.0_deepseek-3-2-high.
  6. По 500 задач; железо не указано. Четыре заявки: OpenHands (80/100, 77,6%), live-SWE-agent (80/100, 79,2%), Sonar Foundation Agent (77/100, 79,2%), mini-SWE-agent, high (79/100, 76,8%). Более ранний запуск mini-SWE-agent дал 74/100, 74,4%.
  7. 500 задач, одна попытка; железо не указано. Источник: experiments, 20251120_livesweagent_gemini-3-pro-preview. Та же модель с mini-SWE-agent: 72/100, 74,2%.
  8. Лучшая опубликованная модель на 20–40 млрд параметров в рейтинге. 500 задач; масштабирование на этапе теста использует две и более попытки на задачу; железо не указано. Источники: масштабирование на этапе теста, одна попытка.
  9. 500 задач, одна попытка; железо не указано. Источник: experiments, 20251209_mini-v1.17.2_devstral-small-2512.
  10. Собственная цифра GitHub, апрель 2025: «agent mode achieves a pass rate of 56.0% on SWE-bench Verified with Claude 3.7 Sonnet». Число задач, попыток и железо не указаны; в рейтинге нет. Источник: блог GitHub.
  11. Anthropic публикует SWE-bench Verified для своих моделей Claude, запущенных в собственной простой обвязке (инструмент bash и инструмент редактирования), а не для продукта Claude Code. Источники: Claude Code, методика Anthropic для SWE-bench.
  12. Cursor публикует результаты на собственном бенчмарке Cursor Bench, а не на SWE-bench Verified. Источник: блог Cursor, Composer.

Все цифры рейтинга: swebench.com и репозиторий SWE-bench/experiments; «те же 100 задач» — это опубликованные результаты каждой заявки по задачам, ограниченные теми, что прогонял Mightling.

FAQ

Нужен ли мне GB10?

Да, чтобы запускать модель. Ваши остальные компьютеры — клиенты, которые берут её у GB10: Linux (Arm или x86) и macOS с той же командой установки и Windows (Arm или x86, предварительная версия) со строкой для PowerShell.

Я установил Puffin. Это та же программа?

Да. В 1.5 Puffin переименовали в Mightling. Один раз выполните puffin update, потом ещё раз в последний раз запустите puffin. Он перенесёт ваши сессии, настройки и ссылки, и после этого команда будет ling.

Это правда ничего не стоит?

Ни программа, ни модель ничего не стоят. Mightling — открытый код под лицензией AGPL, а веса модели можно использовать бесплатно. Вы платите за машину и за электричество, которое она потребляет.

Что нужно, кроме самой машины?

Операционная система, которая в комплекте (DGX OS 7 или Ubuntu 24.04, где NVIDIA её предлагает), Docker с NVIDIA Container Toolkit, Python 3 и Git. На обычной Ubuntu ling-admin host check покажет, чего не хватает.

Уходит ли что-нибудь в интернет?

Только то, о чём просите вы или помощник, например веб-поиск (через SearXNG, который работает на вашей машине) и загрузки при первом использовании. При /airgapped on всё это выключено.

Какую модель он запускает?

Qwen3.8-27B в 4-битном формате NVIDIA под названием NVFP4, его обслуживает SGLang с маленьким помощником-угадчиком под названием DFlash2 drafter. Всё это мы выбрали и настроили под GB10. Веса занимают около 20 ГБ, и пока модель работает, около 38 ГБ памяти машины остаются свободными.

Храните свой код у себя на столе

Если вы считаете, что код должен оставаться на столе, где его написали, поставьте звезду репозиторию на GitHub. Так другие владельцы GB10 находят Mightling.
