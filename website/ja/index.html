v1.7.0 →

1.7.0 にはほかにも、Night Shift が 1 つのタスクを複数回試して最良の結果を残せること（/night add --best-of N）、1 台のマシンで複数の Signal ブリッジを動かせること、同じネットワーク上に 2 つのノードがあってもクライアントが選べて、既知のノードを見失わないこと、が加わりました。リリースノートとダウンロード。

インストール

$ curl -fsSL https://github.com/dreamference/mightling/releases/latest/download/install.sh | bash
$ ling-admin server start      # モデルは初回に 1 度だけダウンロードし（約 20 GB）、その後は配信します
$ cd ~/your-project && ling    # これだけです

NVIDIA DGX Spark とすべての GB10 マシンで動作します。スクリプトは各ダウンロードをリリースのチェックサムで検証し、sudo コマンドは実行前に毎回表示します。気になる方は、先にスクリプトを読むこともできます。

Mac と Linux のクライアント

ほかのコンピュータは、ローカルネットワーク越しに GB10 のモデルを使います。Mac や別の Linux マシンでも、上と同じコマンドで ling クライアントがインストールされ、GB10 は自動的に見つかります。

1.7.2 からは、Mac では「アプリケーション」にデスクトップアプリも入り、すぐ開けます（入れたくない場合は --no-app)。

Windows クライアント プレビュー

> irm https://github.com/dreamference/mightling/releases/latest/download/install.ps1 | iex

PowerShell で実行します。管理者権限なしでインストールでき（1.7.2 からはデスクトップアプリも同様）、そのあと Windows がエージェントのサンドボックスを設定するかどうか 1 度だけ確認します。まだ署名されていないため、スマート アプリ コントロール（Smart App Control）をオフにしておく必要があります。スクリプトを読む。

そのほかのインストール方法

リリースページには、Mac 用の dmg（Mightling-<version>-arm64-preview.dmg、Intel は x64）と、Windows 用インストーラ（Mightling-Setup-<version>-x64.exe、または arm64）もあります。いずれも署名のないプレビュー版で、ブラウザでダウンロードすると初回はブロックされます。先にリリースの署名付き SHA256SUMS と照合してください。

  • macOS 15 以降：Mightling を「アプリケーション」にドラッグして 1 度開き、システム設定 › プライバシーとセキュリティ › このまま開く を選びます。macOS 14 以前では、アプリを Control キーを押しながらクリック › 開く。
  • Windows:SmartScreen › 詳細情報 › 実行。スマート アプリ コントロール（Smart App Control）はオフにしておく必要があります。

まずはこれを試してみてください

あるいは /night add <task> で今夜の作業をキューに入れておきます。寝ている間に Mightling がキューを順にこなし、各タスクはそれぞれ専用の git ブランチに作られます。朝のコーヒーを飲みながらブランチをレビューするだけです。

$ ling "explain this repository to me like I'm new on the team"
# reads the code index (ling-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ling "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ling-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

できること

Mightling 1.7.0 のデスクトップアプリは、Ask と Work を 1 つのウィンドウにまとめました。Work はエージェントセッションのための本格的な作業台です。ファイル、スキル、コマンドを扱えるコンポーザー、ステージ・取り消し・コミットができるレビューペイン、ワークツリー、ターミナルタブ、スレッドの横にあるファイルツリーとファイルタブを備えています。ほかのコンピュータでは GB10 のクライアントとして動作し、GB10 はローカルネットワーク上で自動的に見つかります。

読み取り専用で、サインイン情報はあなたのマシンから出ません。/airgapped on では完全にオフになります。

コードは手元から出ません。しかも、それを自分で確かめられます

クラウドのコーディングエージェントは、ソースコードを他人のサーバーに送ります。Mightling はどこにも送りません。モデルはあなたの GB10 で動き、Mightling の中に外へ通信するものは何もありません。利用状況の分析も、メトリクスも、サインインも、「匿名」のクラッシュレポートもありません。だから、アップロードが許されないコードにも使えます。顧客の案件、規制対象のデータ、未発表の製品などです。

コマンド 1 つで、実際の Mightling セッションを strace の下で実行し、確立されたすべてのネットワーク接続を一覧にします：

$ ling-admin audit egress
✔ Egress audit: pass
Network destinations:
   127.0.0.1:8000     29x  model server
   127.0.0.1:8767      1x  Gmail search service
DNS queries: none
Networked git commands: none

すべて 127.0.0.1 の中で完結しました。DNS の問い合わせは 1 件もありません。

確実な保証が必要ですか？

/airgapped on と入力すると、エージェントが実行するすべてのコマンドに、Linux カーネルから空のネットワーク名前空間が割り当てられます。モデルへのお願いではありません。到達できるネットワークがそもそも存在しないのです。サンドボックスを回避してしまう Full Access も、同時に拒否されます。

外に出るもの、そのタイミング

あなたまたはエージェントが求めたものだけです。Web 検索（自分のマシン上のプライベートな SearXNG 経由）、ページの取得、連携した Google アカウントへの読み取り専用リクエスト、更新の確認。/airgapped on では、そのどれも出ません。

Mightling を選ぶ理由

🔒 機密性

モデルも、コードも、プロンプトも、回答も、それがあるマシンの外には出ません。

  • アカウントなし、テレメトリなし
  • 何度でも再実行できるエグレス監査
  • /airgapped on はカーネルが強制

⚡ 速くて、請求なし

エージェント作業~48 tok/s
コード69 tok/s
JSON84 tok/s
文章32 tok/s
コードの読み込み~1,800 tok/s
コンテキスト262K

GB10 上で投機的デコーディングを使った単一ストリームの速度です。エージェント作業は実際のエージェントセッションで、コード・JSON・文章は出力の種類ごとに、greedy デコーディングで測定しています。エージェントを 4 つ同時に走らせても、クォータも「しばらくお待ちください」もありません。

✨ 設定は不要

  • チューニング不要：モデル、コンテキスト、カーネル、投機的デコーディングは GB10 向けに選定済みです。
  • マシンをフリーズさせません：ホストを事前に確認し、ロード中はメモリ負荷を監視します。
  • ほかのマシンから見つかります。同じローカルネットワーク上にあれば自動的に。
  • 更新はコマンド 1 つ：ling update。

SWE-bench Verified、DGX Spark 1 台での実測

2026-10-08、Mightling 1.5.1 のエージェントと Qwen3.8-27B は、DGX Spark 1 台のオフライン環境で SWE-bench Verified の 100 タスク中 68 件を解決しました。固定した 100 タスクのサンプルで、1 タスクにつき 1 回の試行、デフォルトモードです。全 500 タスクに換算すると、推定 ≈69%（95% 区間 63.9–73.4%）になります。これは自分たちのマシンで、一部のサブセットに対して行った自前の測定であり、リーダーボードへの登録ではありません。

順位表ではなく、比較の目安として読んでください。同じ 100 タスクで、Mightling は自分の何倍もの規模の Qwen3-Coder-480B や GLM-4.6 と同数のタスクを解決しました。ただし、行ごとにエージェントもハードウェアも異なり、リーダーボードの行は公式の x86 テストイメージで評価されている一方、こちらはコミュニティ製の arm64 イメージで実行しています。refine モードでは、最初のセッションが何も変更せずにタスクを調べ、新しいセッションが実作業を行います。解決数はデフォルトより 1 件多い 69 件（68 件に対して。互いに相手が落としたタスクを解いています）で、タスクあたりの時間は約 2.2 倍かかるため、引き続きオプトインです（ling --refine)。

≈69% の推定方法

100 タスクは Verified の 5 分の 1 にすぎないので、全体の数値は推定です。公開されている Verified の全 175 件の提出について、タスクごとの結果に 1 パラメータの項目反応（Rasch）モデルを当てはめます。各タスクに難易度、各システムに能力を割り当てるモデルです。Mightling の能力は、この 100 タスクで 68 件解決を説明する値で、≈69% はその能力の全 500 タスクでの期待スコアです（公表スコアに対する単純な回帰とも 1 ポイント以内で一致します）。検証のため、公開されているすべての提出をこの 100 タスクだけで採点し、全体スコアを同じ方法で予測しました。誤差は 2.4 ポイント（RMSE）で、上の区間はその ±1.96 倍です。表のすべての数値は、SWE-bench/experiments の公開されたタスクごとのデータから scripts/swe_bench_compare.py で再現できます。

100 タスクは、テスト環境が arm64 で動作して検証できるタスク（正解パッチは通り、空の変更は失敗する）の中から、Verified の各リポジトリに全体の比率どおりに振り分けています。公開されているシステムは、この 100 タスクでは全 500 タスクより 1.0〜1.5 ポイント低く出るので、このサンプルが易しいわけではありません。これはリーダーボードへの登録ではありません。リーダーボードは SWE-bench チームが自分たちの環境で採点したものです。

FAQ

GB10 は必須ですか？

モデルを動かすには必要です。ほかのコンピュータはクライアントとしてそれを使います。Linux（Arm または x86）と macOS は同じインストールコマンドで、Windows（Arm または x86、プレビュー）はPowerShell の 1 行で使えます。

Puffin をインストールしています。これがその後継ですか？

はい。Puffin は 1.5 で Mightling に名前が変わりました。puffin update を 1 度実行し、そのあと最後にもう 1 度 puffin を実行してください。セッション、設定、リンクが引き継がれ、以降のコマンドは ling になります。

本当に無料ですか？

はい。Mightling は AGPL のオープンソースで、モデルの重みも無料です。かかる費用は電気代だけです。

マシン以外に必要なものは？

付属の OS（DGX OS 7、ベンダーが提供している場合は Ubuntu 24.04）、NVIDIA Container Toolkit 入りの Docker、Python 3、Git です。素の Ubuntu では、ling-admin host check が足りないものを教えてくれます。

インターネットに出ていくものはありますか？

あなたまたはエージェントが求めたものだけです。たとえば自分のマシン上の SearXNG 経由の Web 検索や、初回のダウンロードがそうです。/airgapped on にすると、そのすべてが止まります。

どのモデルが動きますか？

NVIDIA の 4 ビット NVFP4 形式の Qwen3.8-27B を、DFlash2 ドラフターを組み合わせた SGLang で配信します。GB10 向けに選定・チューニングしたものです。重みは約 20 GB で、配信中もマシンのメモリは約 38 GB 空いたままです。

コードは手元に置いておこう

コードは書かれた机の上にとどまるべきだと思うなら、リポジトリにスターをお願いします。ほかの GB10 オーナーが Mightling を見つける手がかりになります。

$ curl -fsSL https://github.com/dreamference/mightling/releases/latest/download/install.sh | bash
