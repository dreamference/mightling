Install

$ curl -fsSL https://github.com/dreamference/mightling/releases/latest/download/install.sh | bash
$ ling-admin server start      # e go download di model once (~20 GB), then e go start am
$ cd ~/your-project && ling    # na so e be

Dis one dey work for di NVIDIA DGX Spark and for every oda GB10 machine. Di script dey check each download against di release checksums, and e dey show you each sudo command before e run am. You fit read di script first.

Mac and Linux clients

Your oda computers dey borrow di GB10 model for your house or office network. For Mac or another Linux machine, di same command dey install ling, di part wey you dey type inside. E dey find di GB10 by itself.

From 1.7.2 e dey put di desktop app inside Applications for Mac too, ready to open. Add --no-app if you no want am.

Windows client preview

> irm https://github.com/dreamference/mightling/releases/latest/download/install.ps1 | iex

Type dis one inside PowerShell. E no need administrator rights (from 1.7.2 dat one include di desktop app too). Then Windows go ask you one time to set up one closed place where di agent go run commands. Di installer no get signature yet, so Smart App Control must dey off. Read di script.

Oda ways to install

Di release page get di Mac disk image too (Mightling-<version>-arm64-preview.dmg, or x64 for Intel) and di Windows installer (Mightling-Setup-<version>-x64.exe, or arm64). Dem na unsigned previews, so when you download dem for browser, your system go stop dem di first time. Before you open one, check am against di release signed SHA256SUMS file.

  • macOS 15 and later: drag Mightling go Applications and open am one time. Then go System Settings › Privacy & Security and press Open Anyway. For macOS 14 and earlier, Control-click di app and choose Open.
  • Windows: SmartScreen › More info › Run anyway. Smart App Control must dey off.

Try dis ones first

Or leave work for tonight with /night add <task>. Mightling go go through di list while you dey sleep, each task for its own git branch, and for morning you go look di branches.

$ ling "explain this repository to me like I'm new on the team"
# reads the code index (ling-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ling "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ling-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

Your code dey stay for your table, and you fit check say e dey so

Cloud coding agent dey send your source code go computers wey belong to somebody else. Mightling no dey send am anywhere. Di model dey run for your GB10, and nothing inside Mightling dey phone home: no usage counts, no measurements, no sign-in, even "anonymous" crash reports no dey. So you fit use am for code wey dem no allow you upload, like client work, protected data or product wey never release.

One command dey run real Mightling session under strace, tool wey dey watch every call wey program make, then e go list each network connection wey di session open:

$ ling-admin audit egress

   127.0.0.1:8767      1x  Gmail search service
DNS queries: none

Everything stay for 127.0.0.1, wey be di machine dey talk to itself. Not even one DNS lookup (DNS lookup na to ask di internet for di address of one name).

You want firm guarantee?

Type /airgapped on. Every command wey di agent run go then get empty network from di Linux kernel. Dat one no be polite request to di model. Network just no dey to reach. For di same time, Full Access, wey fit go round di sandbox, dem go refuse am.

Wetin fit comot, and when

Only wetin you or di agent ask for: web search (through private SearXNG wey dey run for your own machine, though di search itself still dey go out to di web), fetch of web page, read-only request to Google account wey you connect, or check for updates. With /airgapped on, none of dem go happen.

Why na Mightling

🔒 Private

Di model, your code, your questions and im answers stay for di machine wey dem dey.

  • No account, no tracking
  • Egress audit wey you fit run again
  • /airgapped on, wey kernel enforce

⚡ Fast, and no bill

Na speeds for one task at a time for one GB10. Di model dey use trick wey dem call speculative decoding: small helper dey guess many words ahead and di big model dey check all di guesses at once. "Work for code" dem measure am over real agent sessions. Writing code, JSON and prose, dem measure each for dat kind output. Di last line na how much text e fit hold for mind at once, 262K tokens, wey be few hundred pages. Run four agents at once if you like. No quota, no "abeg wait".

✨ Small to set up

  • No tuning: we choose di model, di memory size, di low-level code and di speculative decoding for di GB10.
  • E no suppose freeze your machine: e dey check di machine before e load di model, and e dey watch memory while e dey load.
  • Your oda computers go find am for your network.
  • Update na one command: ling update.

SWE-bench Verified, wey we measure for one DGX Spark

SWE-bench Verified na set of 500 real problems wey dem take from open-source programs. For each one, di agent must change di code so di tests go pass. On 2026-10-08 we give 100 of dem to Mightling 1.5.1, wey dey use di Qwen3.8-27B model, for one DGX Spark without internet. E get one try for each, for im default mode, and e solve 68 out of di 100. If we scale am up to all 500, we estimate about 69%, give or take few points (di 95% range na 63.9 to 73.4%). We measure dis one ourselves, for our own machine, for sample of di problems. Na no be entry for di official leaderboard.

Read dis table as way to see who dey near, no be ranking. For di same 100 problems, Mightling solve as many as Qwen3-Coder-480B and GLM-4.6, models wey big pass am many times. But every row dey use different agent program and different hardware, and di leaderboard rows use di official test images for x86 computers, while ours run for community images for arm64. Another mode still dey, wey dem call refine. First session go study di problem and e no go change anything, then fresh session go do di work. E solve one more problem than di default (69 against 68, and each mode solve some problems wey di oda one miss), and e take about 2.2 times as long for each problem. So e dey off unless you ask for am with ling --refine.

How we estimate di 69%

100 problems na one-fifth of Verified, so di figure for all 500 na estimate. Na so we take do am. Take di results of all 175 public Verified submissions, problem by problem. Give every problem difficulty and every system ability, with one-parameter item-response (Rasch) model. Mightling ability na di one wey go solve 68 for dis 100 problems, and about 69% na wetin dat ability go score for all 500. Plain regression on di published scores agree within one point. We also check di method on oda people: for every public submission we use only im score for dis 100 problems to predict im score for all 500. Di error na 2.4 points (RMSE), and di range above na 1.96 times dat one for each side. You fit reproduce every number inside di table with scripts/swe_bench_compare.py, from di public per-problem data for SWE-bench/experiments.

We spread di 100 problems across di programs inside Verified for di same proportions as di full set. We draw dem from di problems wey their test setup dey work and check out for arm64 (di correct fix go pass, and to do nothing go fail). Published systems score 1.0 to 1.5 points lower for dis 100 than for all 500, so di sample no easy. Still, e no be leaderboard entry, because di SWE-bench team dey grade those ones for their own machines.

FAQ

I need GB10?

Yes, to run di model. Your oda computers na clients wey dey borrow am: Linux (Arm or x86) and macOS with di same install command, and Windows (Arm or x86, preview) with di PowerShell line.

I install Puffin. Na di same program?

Yes. Dem rename Puffin to Mightling for 1.5. Run puffin update once, then run puffin one last time. E go move your sessions, settings and links come, and after dat di command na ling.

E really cost nothing?

Nothing for di program or for di model. Mightling na open source under di AGPL, and di model weights free to use. You go pay for di machine and di electricity wey e dey use.

Wetin I need apart from di machine?

Di operating system wey e come with (DGX OS 7, or Ubuntu 24.04 where NVIDIA dey offer am), Docker with di NVIDIA Container Toolkit, Python 3 and Git. For plain Ubuntu, ling-admin host check go tell you wetin miss.

Anything dey ever go out to di internet?

Only wetin you or di agent ask for, like web search (through SearXNG wey dey run for your own machine) and di downloads for first use. With /airgapped on, all of dem dey off.

Which model e dey run?

Qwen3.8-27B, for NVIDIA 4-bit format wey dem call NVFP4, wey SGLang dey serve with small guessing helper wey dem call DFlash2 drafter. We choose and tune all of am for di GB10. Di weights take about 20 GB, and while e dey run, about 38 GB of di machine memory go still free.

If you think say code suppose stay for di table where dem write am, star di repository for GitHub. Na so oda GB10 owners dey find Mightling.
