How we estimate di ≈69%

100 tasks na one fifth of Verified, so di full-set figure na estimate. We fit one-parameter item-response (Rasch) model on di per-task results of all 175 public Verified submissions: every task get difficulty and every system get ability. Mightling ability na di one wey explain 68 solved for these 100 tasks; ≈69% na di expected score of dat ability for all 500 (plain regression on di published scores agree within one point). To check am, we score every public submission for these 100 tasks alone and predict im overall score di same way: di error na 2.4 points (RMSE), and di band wey dey up na ±1.96 times dat. Every number for di table, scripts/swe_bench_compare.py dey reproduce am from di public per-task data of SWE-bench/experiments.

Di 100 tasks spread across Verified repositories in proportion to di full set, among di tasks wey dia test environment dey run and validate for arm64 (di gold patch pass, empty change fail). Published systems score 1.0 to 1.5 points lower for these 100 than for all 500, so di sample no easy. E no be leaderboard entry: SWE-bench team dey grade those one for dia own infrastructure.

Your code no dey leave your table — and you fit prove am

Cloud coding agents dey send your source code go anoda person servers. Mightling no dey send am anywhere: di model dey run for your GB10, and nothing inside Mightling dey phone home. No usage analytics, no metrics, no sign-in, no "anonymous" crash reports. Dat one make e fit work for code wey dem no allow you upload: client work, regulated data, unreleased products.

You need hard guarantee?

Type /airgapped on and every command wey di agent run go get empty network namespace from di Linux kernel. E no be polite request to di model: network just no dey to reach. Full Access, wey for bypass di sandbox, dem go refuse am for di same time.

Only wetin you or di agent ask for: web search (through private SearXNG for your own machine), page fetch, read-only request to Google account wey you connect, or update check. For /airgapped on, none of dem.

FAQ

I need GB10?

Yes, to run di model. Your oda computers dey use am as clients: Linux (Arm or x86) and macOS with di same install command, Windows (Arm or x86, preview) with di PowerShell line.

I don install Puffin. Na dis one?

Yes: dem rename Puffin to Mightling for 1.5. Run puffin update once, then puffin one last time. E go move your sessions, settings and links come, and from then di command na ling.

E really free?

Yes. Mightling na open source under di AGPL, and di model weights free. Di only running cost wey you get na electricity.

Wetin I need apart from di machine?

Di OS wey e come with (DGX OS 7, or Ubuntu 24.04 where di vendor offer am), Docker with di NVIDIA Container Toolkit, Python 3 and Git. For plain Ubuntu, ling-admin host check go tell you wetin dey miss.

Anything dey ever reach internet?

Only wetin you or di agent ask for, like web search through SearXNG for your own machine, and di first-time downloads. /airgapped on dey turn all of am off.

Which model e dey run?

Qwen3.8-27B for NVIDIA 4-bit NVFP4 format, wey SGLang dey serve with DFlash2 drafter, dem choose and tune am for di GB10. About 20 GB of weights; roughly 38 GB of di machine memory go remain free while e dey serve.
