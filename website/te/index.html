1.7.0 లో ఇంకా: Night Shift ఒక టాస్క్‌ను అనేకసార్లు ప్రయత్నించి ఉత్తమ ప్రయత్నాన్ని ఉంచుకోగలదు (/night add --best-of N), ఒక మెషీన్ అనేక Signal బ్రిడ్జ్‌లను నడపగలదు, ఒకే నెట్‌వర్క్‌లో రెండు నోడ్‌ల మధ్య క్లయింట్ ఎంచుకుంటుంది, తనకు తెలిసిన దాన్ని కోల్పోదు. రిలీజ్ నోట్స్, డౌన్‌లోడ్‌లు.

ఇన్‌స్టాల్

$ curl -fsSL https://github.com/dreamference/mightling/releases/latest/download/install.sh | bash
$ ling-admin server start      # మోడల్‌ను ఒక్కసారి డౌన్‌లోడ్ చేస్తుంది (~20 GB), తర్వాత సర్వ్ చేస్తుంది
$ cd ~/your-project && ling    # అంతే

NVIDIA DGX Spark మీద, అన్ని GB10 మెషీన్ల మీద పనిచేస్తుంది. స్క్రిప్ట్ ప్రతి డౌన్‌లోడ్‌ను రిలీజ్ చెక్‌సమ్‌లతో సరిచూస్తుంది, ప్రతి sudo కమాండ్‌ను నడిపే ముందు చూపిస్తుంది. కావాలంటే ముందు దాన్ని చదవండి.

Mac, Linux క్లయింట్లు

మీ ఇతర కంప్యూటర్లు లోకల్ నెట్‌వర్క్ ద్వారా GB10 మోడల్‌ను వాడుకుంటాయి. Mac లేదా మరో Linux మెషీన్‌లో పైన ఉన్న అదే కమాండ్ ling క్లయింట్‌ను ఇన్‌స్టాల్ చేస్తుంది; అది GB10 ను తనంతట తానే కనుగొంటుంది.

1.7.2 నుండి ఇది Mac లో డెస్క్‌టాప్ యాప్‌ను కూడా Applications లో తెరవడానికి సిద్ధంగా ఉంచుతుంది (--no-app దాన్ని వదిలేస్తుంది).

Windows క్లయింట్ ప్రివ్యూ

> irm https://github.com/dreamference/mightling/releases/latest/download/install.ps1 | iex

PowerShell లో. అడ్మినిస్ట్రేటర్ హక్కులు లేకుండా ఇన్‌స్టాల్ అవుతుంది (1.7.2 నుండి డెస్క్‌టాప్ యాప్ కూడా), తర్వాత ఏజెంట్ శాండ్‌బాక్స్ సెటప్ కోసం Windows ఒక్కసారి అడుగుతుంది. ఇంకా సైన్ చేయలేదు, కాబట్టి Smart App Control ఆఫ్‌లో ఉండాలి. స్క్రిప్ట్ చదవండి.

ఇన్‌స్టాల్ చేయడానికి ఇతర మార్గాలు

రిలీజ్ పేజీలో Mac dmg (Mightling-<version>-arm64-preview.dmg, Intel కోసం x64), Windows ఇన్‌స్టాలర్ (Mightling-Setup-<version>-x64.exe, లేదా arm64) కూడా ఉంటాయి. ఇవి సైన్ చేయని ప్రివ్యూలు: బ్రౌజర్‌లో డౌన్‌లోడ్ చేస్తే మొదటిసారి ఆపేస్తాయి. ముందు ప్రతిదాన్ని రిలీజ్ సైన్ చేసిన SHA256SUMS తో సరిచూడండి.

  • macOS 15 మరియు తర్వాత: Mightling ను Applications లోకి లాగి ఒకసారి తెరవండి, తర్వాత System Settings › Privacy & Security › Open Anyway. macOS 14 మరియు అంతకు ముందు: యాప్ మీద Control-క్లిక్ › Open.
  • Windows: SmartScreen › More info › Run anyway. Smart App Control ఆఫ్‌లో ఉండాలి.

ముందు వీటిని ప్రయత్నించండి

లేదా ఈ రాత్రికి పనిని క్యూలో పెట్టండి: /night add <task>. మీరు నిద్రపోయే సమయంలో Mightling క్యూను పూర్తి చేస్తుంది, ప్రతి టాస్క్ దాని సొంత git బ్రాంచ్‌లో, ఉదయం కాఫీ తాగుతూ బ్రాంచ్‌లను సమీక్షించండి.

$ ling "explain this repository to me like I'm new on the team"
# reads the code index (ling-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ling "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ling-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

1.7.2 నుండి ఇన్‌స్టాల్ కమాండ్ Mightling ను ling పక్కనే Applications లో ఉంచుతుంది, ఇతర యాప్‌ల్లాగే తెరుచుకుంటుంది. Apple silicon, Intel, macOS 12 లేదా ఆ తర్వాత. ling update దాన్ని అప్‌డేట్ చేస్తుంది.

GB10 మీద mightling_1.7.0_arm64.deb యాప్‌ను, దాని లాంచర్ ఎంట్రీని, ling-app కమాండ్‌ను, అవసరమైన శాండ్‌బాక్స్ ప్రొఫైల్‌తో సహా ఇన్‌స్టాల్ చేస్తుంది:

$ sudo apt install ./mightling_1.7.0_arm64.deb

తర్వాత అప్లికేషన్ మెనూ నుండి లేదా ling app తో తెరవండి. మరింత.

Windows 11 ప్రివ్యూ

1.7.2 నుండి PowerShell లైన్ యాప్‌ను కూడా ఇన్‌స్టాల్ చేస్తుంది, మీకు మాత్రమే, అడ్మినిస్ట్రేటర్ హక్కులు లేకుండా, Start మెనూ ఎంట్రీతో; Settings → Apps నుండి తొలగించవచ్చు; ling update అప్‌డేట్ చేస్తుంది. Smart App Control ఆఫ్‌లో ఉండాలి.

JetBrains, VS Code మరియు మీ ఫోన్

చదవడానికి మాత్రమే, మీ మెషీన్‌లోనే ఉండే సైన్-ఇన్ ద్వారా. /airgapped on లో పూర్తిగా ఆఫ్.

మీ కోడ్ మీ డెస్క్ దాటదు, అది మీరు నిరూపించవచ్చు

క్లౌడ్ కోడింగ్ ఏజెంట్లు మీ సోర్స్ కోడ్‌ను ఇతరుల సర్వర్లకు పంపుతాయి. Mightling దాన్ని ఎక్కడికీ పంపదు: మోడల్ మీ GB10 మీదే నడుస్తుంది, Mightling లో ఏదీ బయటికి సంప్రదించదు. వినియోగ విశ్లేషణలు, మెట్రిక్స్, సైన్-ఇన్, “అనామక” క్రాష్ రిపోర్టులు ఏవీ లేవు. అందువల్ల అప్‌లోడ్ చేయడానికి అనుమతి లేని కోడ్‌కు ఇది వాడదగినది: క్లయింట్ పని, నియంత్రిత డేటా, విడుదల కాని ఉత్పత్తులు.

ఒక కమాండ్ నిజమైన Mightling సెషన్‌ను strace కింద నడిపి, అది చేసిన ప్రతి నెట్‌వర్క్ కనెక్షన్‌ను జాబితా చేస్తుంది:

కచ్చితమైన హామీ కావాలా?

/airgapped on అని టైప్ చేయండి; ఏజెంట్ నడిపే ప్రతి కమాండ్‌కు Linux కెర్నెల్ ఖాళీ నెట్‌వర్క్ నేమ్‌స్పేస్ ఇస్తుంది. ఇది మోడల్‌ను మర్యాదగా అడగడం కాదు: చేరుకోవడానికి నెట్‌వర్క్ అసలే ఉండదు. శాండ్‌బాక్స్‌ను దాటవేసే Full Access అదే సమయంలో తిరస్కరించబడుతుంది.

ఏమి బయటికి వెళ్లవచ్చు, ఎప్పుడు

మీరు లేదా ఏజెంట్ అడిగినదే: వెబ్ సెర్చ్ (మీ సొంత మెషీన్‌లోని ప్రైవేట్ SearXNG ద్వారా), పేజీ ఫెచ్, మీరు కనెక్ట్ చేసిన Google ఖాతాకు చదవడానికి మాత్రమే అభ్యర్థన, లేదా అప్‌డేట్ తనిఖీ. /airgapped on లో వీటిలో ఏదీ లేదు.

SWE-bench Verified, ఒక DGX Spark మీద కొలిచినది

2026-10-08 న Qwen3.8-27B తో Mightling 1.5.1 ఏజెంట్ ఒక DGX Spark మీద ఆఫ్‌లైన్‌లో SWE-bench Verified లో 100 లో 68 టాస్క్‌లు పరిష్కరించింది: 100 టాస్క్‌ల స్థిర నమూనా, ప్రతి టాస్క్‌కు ఒక ప్రయత్నం, డిఫాల్ట్ మోడ్. మొత్తం 500 టాస్క్‌లకు విస్తరిస్తే ఇది అంచనా ≈69% (95% పరిధి 63.9–73.4%). ఇది మా సొంత యంత్రంపై, ఒక ఉపసమితిపై, మేమే చేసిన కొలత; లీడర్‌బోర్డ్ ఎంట్రీ కాదు.

దీన్ని ర్యాంకింగ్‌లా కాకుండా సహచర మోడల్స్‌తో పోలికగా చదవండి. అవే 100 టాస్క్‌లపై Mightling, తనకంటే ఎన్నో రెట్లు పెద్ద మోడల్స్ అయిన Qwen3-Coder-480B, GLM-4.6 లతో సమానంగా పరిష్కరించింది; కానీ ప్రతి వరుసలో ఏజెంట్ వేరు, హార్డ్‌వేర్ వేరు, లీడర్‌బోర్డ్ వరుసల్లో అధికారిక x86 టెస్ట్ ఇమేజ్‌లు, మాది కమ్యూనిటీ arm64 ఇమేజ్‌లపై నడిచింది. refine మోడ్‌లో మొదటి సెషన్ ఏమీ మార్చకుండా టాస్క్‌ను అధ్యయనం చేస్తుంది, కొత్త సెషన్ దాన్ని చేస్తుంది: ఇది డిఫాల్ట్ కంటే ఒక టాస్క్ ఎక్కువ పరిష్కరించింది (69 వర్సెస్ 68, ఒక్కో మోడ్ మరో మోడ్ విఫలమైన టాస్క్‌లు గెలిచింది), ప్రతి టాస్క్‌కు సుమారు 2.2 రెట్లు సమయంతో, అందుకే ఇది ఐచ్ఛికంగానే ఉంది (ling --refine).

≈69% ను ఎలా అంచనా వేశారు

100 టాస్క్‌లు Verified లో ఐదవ వంతు, కాబట్టి పూర్తి సెట్ సంఖ్య ఒక అంచనా. Verified కి సమర్పించిన మొత్తం 175 పబ్లిక్ ఫలితాల ప్రతి-టాస్క్ ఫలితాలపై ఒక-పారామీటర్ ఐటెమ్-రెస్పాన్స్ (Rasch) మోడల్‌ను ఫిట్ చేశారు: ప్రతి టాస్క్‌కు కష్టం, ప్రతి సిస్టమ్‌కు సామర్థ్యం. ఈ 100 టాస్క్‌లలో 68 పరిష్కారాన్ని వివరించేదే Mightling సామర్థ్యం; ≈69% అనేది ఆ సామర్థ్యం మొత్తం 500 పై పొందే అంచనా స్కోరు (ప్రచురిత స్కోర్లపై సాధారణ రిగ్రెషన్ ఒక పాయింట్ లోపే ఏకీభవిస్తుంది). ధృవీకరణ కోసం ప్రతి పబ్లిక్ సమర్పణను ఈ 100 టాస్క్‌లపైనే స్కోర్ చేసి, దాని మొత్తం స్కోరును అదే విధంగా అంచనా వేశారు: లోపం 2.4 పాయింట్లు (RMSE), పై పరిధి దానికి ±1.96 రెట్లు. పట్టికలోని ప్రతి సంఖ్యను scripts/swe_bench_compare.py పునరుత్పత్తి చేస్తుంది, SWE-bench/experiments లోని పబ్లిక్ ప్రతి-టాస్క్ డేటా నుండి.

ఈ 100 టాస్క్‌లు Verified రిపాజిటరీలలో పూర్తి సెట్ నిష్పత్తిలో పంచబడ్డాయి; వాటి టెస్ట్ ఎన్విరాన్‌మెంట్ arm64 మీద నడిచి ధృవీకరణ అయ్యే టాస్క్‌ల నుండి (గోల్డ్ ప్యాచ్ పాస్ అవుతుంది, ఖాళీ మార్పు ఫెయిల్ అవుతుంది). ప్రచురిత సిస్టమ్‌లు ఈ 100 పై మొత్తం 500 కంటే 1.0 నుండి 1.5 పాయింట్లు తక్కువ స్కోరు చేస్తాయి, కాబట్టి నమూనా తేలికైనది కాదు. ఇది లీడర్‌బోర్డ్ ఎంట్రీ కాదు: అవి SWE-bench బృందం తమ సొంత ఇన్‌ఫ్రాస్ట్రక్చర్ మీద గ్రేడ్ చేస్తుంది.

ప్రశ్నలు

నాకు GB10 కావాలా?

అవును, మోడల్ నడపడానికి. మీ ఇతర కంప్యూటర్లు దాన్ని క్లయింట్లుగా వాడుతాయి: Linux (Arm లేదా x86), macOS అదే ఇన్‌స్టాల్ కమాండ్‌తో, Windows (Arm లేదా x86, ప్రివ్యూ) PowerShell లైన్ తో.

నేను Puffin ఇన్‌స్టాల్ చేశాను. ఇదే అదా?

అవును: 1.5 లో Puffin పేరు Mightling గా మారింది. ఒకసారి puffin update నడపండి, ఆ తర్వాత చివరిసారి puffin. ఇది మీ సెషన్లు, సెట్టింగ్‌లు, లింక్‌లను తరలిస్తుంది; అప్పటి నుండి కమాండ్ ling.

ఇది నిజంగా ఉచితమేనా?

అవును. Mightling AGPL కింద ఓపెన్ సోర్స్, మోడల్ వెయిట్‌లు ఉచితం. మీకు అయ్యే నిర్వహణ ఖర్చు కరెంటు మాత్రమే.

మెషీన్ కాకుండా నాకు ఇంకా ఏమి కావాలి?

దానితో వచ్చే OS (DGX OS 7, లేదా విక్రేత ఇచ్చే చోట Ubuntu 24.04), NVIDIA Container Toolkit తో Docker, Python 3, Git. సాధారణ Ubuntu లో ling-admin host check ఏమి లేదో చెబుతుంది.

ఏదైనా ఎప్పుడైనా ఇంటర్నెట్‌కు చేరుతుందా?

మీరు లేదా ఏజెంట్ అడిగినదే, ఉదాహరణకు మీ సొంత మెషీన్‌లోని SearXNG ద్వారా వెబ్ సెర్చ్, మొదటిసారి డౌన్‌లోడ్‌లు. /airgapped on వాటన్నిటినీ ఆపేస్తుంది.

ఇది ఏ మోడల్ నడుపుతుంది?

NVIDIA 4-బిట్ NVFP4 ఫార్మాట్‌లో Qwen3.8-27B, DFlash2 డ్రాఫ్టర్‌తో SGLang ద్వారా సర్వ్ అవుతుంది, GB10 కోసం ఎంచుకుని ట్యూన్ చేసినది. వెయిట్‌లు సుమారు 20 GB; సర్వ్ చేస్తున్నప్పుడు మెషీన్ మెమరీలో సుమారు 38 GB ఖాళీగా ఉంటుంది.
