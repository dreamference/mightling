v1.7.0 →

1.7.0 मध्ये हेही आहे: Night Shift एका कामाचा अनेक वेळा प्रयत्न करू शकते आणि सर्वोत्तम प्रयत्न ठेवू शकते (/night add --best-of N). एक मशीन अनेक Signal ब्रिज चालवू शकते. आणि एका नेटवर्कवर दोन GB10 दिसणारा संगणक त्यांच्यातून एक निवडू शकतो, आणि आधीपासून ओळखीचा असलेला विसरत नाही. रिलीझ नोट्स आणि डाउनलोड.

इन्स्टॉल

$ curl -fsSL https://github.com/dreamference/mightling/releases/latest/download/install.sh | bash
$ ling-admin server start      # मॉडेल एकदाच डाउनलोड होते (~20 GB), मग सुरू होते
$ cd ~/your-project && ling    # एवढेच

हे NVIDIA DGX Spark वर चालते आणि इतर प्रत्येक GB10 मशीनवरही. स्क्रिप्ट प्रत्येक डाउनलोड रिलीझच्या चेकसमशी पडताळून पाहते, आणि प्रत्येक sudo कमांड चालवण्याआधी तुम्हाला दाखवते. तुम्ही आधी स्क्रिप्ट वाचू शकता.

Mac आणि Linux क्लायंट

तुमचे इतर संगणक घरच्या किंवा ऑफिसच्या नेटवर्कवरून GB10 चे मॉडेल उसने घेतात. Mac किंवा दुसऱ्या Linux मशीनवर हीच कमांड ling बसवते, म्हणजे तुम्ही जिथे टाइप करता तो भाग. तो GB10 आपोआप शोधतो.

1.7.2 पासून हे Mac वर डेस्कटॉप ॲपही Applications मध्ये ठेवते, उघडायला तयार. नको असल्यास --no-app जोडा.

Windows क्लायंट प्रिव्ह्यू

> irm https://github.com/dreamference/mightling/releases/latest/download/install.ps1 | iex

हे PowerShell मध्ये टाइप करा. यासाठी प्रशासकाचे (administrator) अधिकार लागत नाहीत (1.7.2 पासून डेस्कटॉप ॲपसाठीही हेच). मग Windows तुम्हाला एकदा विचारते की सहाय्यक जिथे कमांड चालवतो ती भिंतींनी वेढलेली जागा तयार करायची का. इंस्टॉलरवर अजून सही नाही, म्हणून Smart App Control बंद असले पाहिजे. स्क्रिप्ट वाचा.

इन्स्टॉल करण्याचे इतर मार्ग

रिलीझ पानावर Mac ची डिस्क इमेज (Mightling-<version>-arm64-preview.dmg, किंवा Intel साठी x64) आणि Windows इंस्टॉलर (Mightling-Setup-<version>-x64.exe, किंवा arm64) हेही आहेत. ही सही नसलेली प्रीव्ह्यू आहेत, म्हणून ब्राउझरमधून डाउनलोड केल्यावर तुमची सिस्टीम पहिल्यांदा त्यांना थांबवते. उघडण्याआधी त्यांना रिलीझच्या सही केलेल्या SHA256SUMS फाइलशी पडताळून पाहा.

  • macOS 15 आणि नंतरचे: Mightling ला Applications मध्ये ओढा आणि एकदा उघडा. मग System Settings › Privacy & Security मध्ये जा आणि Open Anyway दाबा. macOS 14 आणि आधीच्यामध्ये ॲपवर Control दाबून क्लिक करा आणि Open निवडा.
  • Windows: SmartScreen › More info › Run anyway. Smart App Control बंद असायला हवे.

आधी हे करून पहा

किंवा आज रात्रीसाठी काम ठेवा: /night add <task>. तुम्ही झोपलेले असताना Mightling यादीवर काम करते, प्रत्येक काम स्वतःच्या वेगळ्या git ब्रांचवर, आणि सकाळी तुम्ही त्या ब्रांच तपासता.

$ ling "explain this repository to me like I'm new on the team"
# reads the code index (ling-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ling "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ling-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

🧭 कोड इंडेक्स

तुमच्या सगळ्या प्रोजेक्टमध्ये गोष्टी कुठे ठरवल्या आहेत आणि त्या कोण वापरते याची यादी, म्हणजे सहाय्यक कोड अंदाजाने शोधण्याऐवजी थेट पाहू शकतो.

🔎 वेब सर्च आणि पेज आणणे

सर्च तुमच्या स्वतःच्या मशीनवरील खाजगी SearXNG मार्फत होते, म्हणून सर्च अकाउंट नाही आणि मिळवायला कोणती किल्ली नाही. प्रश्न तरीही उत्तरासाठी वेबपर्यंत जातात.

🌙 Night Shift

झोपण्यापूर्वी /night add <task> टाइप करा. सकाळपर्यंत प्रत्येक काम स्वतःच्या वेगळ्या git ब्रांचवर झालेले असते. तुम्ही स्वतः केल्याशिवाय काहीही मर्ज किंवा पुश होत नाही.

तुम्हाला काय मिळते

1.7.0 मधील डेस्कटॉप ॲप Mightling वापरण्याचे दोन्ही मार्ग एकाच विंडोत आणते: Ask, जिथे तुम्ही प्रश्न विचारता, आणि Work, जिथे सहाय्यक तुमचा कोड बदलतो. Work मध्ये कामे लिहिण्याचा एक बॉक्स आहे (तुम्ही फाइल्स, स्किल्स आणि कमांड्स जोडू शकता), बदल ठेवण्याआधी किंवा मागे घेण्याआधी ते तपासायला एक पॅनेल आहे, तुमच्या कोडच्या वेगवेगळ्या कामाच्या प्रती (worktrees) आहेत, टर्मिनल टॅब आहेत, आणि संभाषणाशेजारी फाइल्सचे झाड आहे. तुमच्या इतर संगणकांवर हे ॲप तुमच्या GB10 शी बोलते, जो ते तुमच्या नेटवर्कवर शोधते.

ling · ling-code · ling-docs

🖥️ ling, तुमच्या टर्मिनलमधील सहाय्यक

तो तुमचा प्रोजेक्ट वाचतो, कमांड्स आणि चाचण्या चालवतो, कोड बदलतो, आणि धोकादायक काही करण्याआधी तुम्हाला आधी विचारतो.

इन्स्टॉल →
$ ling worktree on   # new sessions start in their own worktree
$ cd ~/your-project && ling
> /airgapped on      # no network for any command it runs
> /worktree apply    # bring the changes back to your checkout

Claude Code, Gemini CLI, OpenClaw किंवा Hermes साठी तुम्ही लिहिलेली स्किल्स इथे आहेत तशीच चालतात.

🪟 डेस्कटॉप ॲप प्रिव्ह्यू

Ask आणि Work एकाच विंडोत, GB10, Mac, Linux किंवा Windows वर. सहाय्यकाची सेशन्स तुमची मंजुरी मागतात, आणि बदल तपासण्याचे पॅनेल, वेगवेगळ्या कामाच्या प्रती आणि पूर्ववत करण्याची सोय आहे. 1.7 मध्ये नवे.

वेब सर्च, इमेज सर्च आणि टाइप करण्याऐवजी बोलून प्रश्न, आणि तुमची सहाय्यक सेशनही, या मशीनवरून किंवा तुम्ही त्याच्याशी जोडलेल्या फोनवरून. हे सगळे तुमच्या मशीनवरील त्याच मॉडेलचा वापर करते.

डॉक्स →

macOS प्रिव्ह्यू

1.7.2 पासून इन्स्टॉल कमांड Mightling ला ling सोबत Applications मध्ये ठेवते, आणि तुम्ही ते इतर कोणत्याही ॲपप्रमाणे उघडता. ते Apple silicon आणि Intel दोन्हीवर चालते, macOS 12 किंवा नंतरच्या आवृत्तीसह. ling update ते अपडेट करते.

Linux

GB10 वर mightling_1.7.0_arm64.deb ही फाइल ॲप, त्याची मेनू एंट्री आणि ling-app कमांड बसवते, तसेच त्याला लागणारी सँडबॉक्स प्रोफाइलही. (सँडबॉक्स म्हणजे कमांड चालवण्याची एक बंद खोली, म्हणजे त्या मशीनच्या बाकीच्या भागाला हात लावू शकत नाहीत.)

$ sudo apt install ./mightling_1.7.0_arm64.deb

मग ते ॲप्लिकेशन मेनूमधून उघडा, किंवा ling app टाइप करा. अधिक माहिती.

Windows 11 प्रिव्ह्यू

1.7.2 पासून PowerShell ची ओळ ॲपही बसवते, फक्त तुमच्यासाठी आणि प्रशासकाच्या अधिकारांशिवाय, Start मेनूमध्ये एका एंट्रीसह. Settings → Apps ते काढून टाकते, आणि ling update ते अपडेट करते. Smart App Control बंद असले पाहिजे.

ling-admin mcp · ling signal · ling chat

JetBrains, VS Code आणि तुमचा फोन

तुम्ही JetBrains किंवा VS Code ला stdio MCP (ling-admin mcp) मार्फत जोडू शकता. तुम्ही तुमच्या GB10 ला Signal वरून (स्वतःलाच, Note to Self मध्ये), Telegram वरून (रिपॉझिटरीवर काम करणाऱ्या Mini App सह) आणि Tailscale वरील Matrix वरूनही संदेश पाठवू शकता. फोनचा प्रत्येक दुवा तुम्ही चालू करेपर्यंत बंद असतो. Signal एंड-टू-एंड एन्क्रिप्टेड आहे, आणि Matrix तुमच्या स्वतःच्या सर्व्हरवर चालते. Telegram चे संदेश एन्क्रिप्शनशिवाय Telegram च्या सर्व्हरमधून जातात, म्हणून ते फक्त अशा गोष्टींसाठी वापरा ज्या अशा प्रकारे शेअर करायला तुमची हरकत नाही.

SWE-bench Verified, एका DGX Spark वर मोजलेले

SWE-bench Verified हा ओपन-सोर्स प्रोग्राम्समधून घेतलेल्या 500 खऱ्या समस्यांचा संच आहे. प्रत्येक समस्येत सहाय्यकाला कोड असा बदलावा लागतो की चाचण्या पास होतील. 2026-10-08 रोजी आम्ही त्यांपैकी 100 Mightling 1.5.1 ला दिल्या, Qwen3.8-27B मॉडेलसह, इंटरनेटशिवाय एका DGX Spark वर. प्रत्येक समस्येवर त्याला त्याच्या डीफॉल्ट मोडमध्ये एकच प्रयत्न मिळाला, आणि त्याने 100 पैकी 68 सोडवल्या. हे सर्व 500 पर्यंत वाढवले तर आमचा अंदाज सुमारे 69% आहे, काही गुणांच्या कमी-जास्तपणासह (95% ची श्रेणी 63.9 ते 73.4% आहे). हे आम्ही स्वतः मोजले आहे, आमच्या स्वतःच्या मशीनवर, समस्यांच्या एका नमुन्यावर. ही अधिकृत लीडरबोर्डवरील नोंद नाही.

आम्ही 69% चा अंदाज कसा लावतो

100 समस्या म्हणजे Verified चा पाचवा भाग, म्हणून सर्व 500 चा आकडा हा अंदाज आहे. आम्ही तो असा बनवला. सर्व 175 सार्वजनिक Verified सबमिशनचे निकाल घ्या, समस्येनुसार. प्रत्येक समस्येला एक काठिण्य आणि प्रत्येक सिस्टीमला एक क्षमता द्या, एक-पॅरामीटर आयटम-रिस्पॉन्स (Rasch) मॉडेलने. Mightling ची क्षमता अशी आहे जी या 100 समस्यांपैकी 68 सोडवेल, आणि सुमारे 69% म्हणजे तीच क्षमता सर्व 500 वर मिळवेल तो गुण. प्रकाशित गुणांवरील साधे रिग्रेशन एका गुणाच्या आत याच्याशी सहमत आहे. आम्ही ही पद्धत इतरांवरही तपासली: प्रत्येक सार्वजनिक सबमिशनसाठी आम्ही फक्त या 100 समस्यांवरील त्याचा गुण घेऊन सर्व 500 वरील त्याच्या गुणाचा अंदाज लावला. त्रुटी 2.4 गुण होती (RMSE), आणि वरची श्रेणी प्रत्येक बाजूला त्याच्या 1.96 पट आहे. तालिकेतील प्रत्येक आकडा scripts/swe_bench_compare.py ने पुन्हा तयार करता येतो, SWE-bench/experiments मधील सार्वजनिक समस्येनुसार डेटावरून.

FAQ

मला GB10 लागेल का?

हो, मॉडेल चालवण्यासाठी. तुमचे इतर संगणक क्लायंट आहेत जे ते उसने घेतात: Linux (Arm किंवा x86) आणि macOS त्याच इन्स्टॉल कमांडने, आणि Windows (Arm किंवा x86, प्रीव्ह्यू) PowerShell च्या ओळीने.

मी Puffin इन्स्टॉल केले होते. हा तोच प्रोग्राम आहे का?

हो. 1.5 मध्ये Puffin चे नाव बदलून Mightling केले. एकदा puffin update चालवा, मग शेवटचे एकदा puffin चालवा. ते तुमची सेशन्स, सेटिंग्ज आणि लिंक्स पुढे नेते, आणि त्यानंतर कमांड ling आहे.

खरंच काहीच खर्च येत नाही का?

प्रोग्रामसाठी काही नाही आणि मॉडेलसाठीही काही नाही. Mightling AGPL अंतर्गत ओपन सोर्स आहे, आणि मॉडेलचे वेट वापरायला मोफत आहेत. तुम्ही मशीनचे आणि त्याच्या विजेचे पैसे देता.

मशीनशिवाय आणखी काय लागते?

त्यासोबत येणारी ऑपरेटिंग सिस्टीम (DGX OS 7, किंवा जिथे NVIDIA देते तिथे Ubuntu 24.04), NVIDIA Container Toolkit सह Docker, Python 3 आणि Git. साध्या Ubuntu वर ling-admin host check काय कमी आहे ते सांगते.

कधी काही इंटरनेटवर बाहेर जाते का?

फक्त तेच जे तुम्ही किंवा सहाय्यक मागता, जसे वेब सर्च (तुमच्या स्वतःच्या मशीनवर चालणाऱ्या SearXNG मार्फत) आणि पहिल्या वापरातील डाउनलोड. /airgapped on ने हे सगळे बंद होते.

ते कोणते मॉडेल चालवते?

Qwen3.8-27B, NVIDIA च्या 4-बिट फॉरमॅट NVFP4 मध्ये, SGLang कडून चालवलेले, आणि DFlash2 ड्राफ्टर नावाच्या छोट्या अंदाज लावणाऱ्या सहाय्यकासह. हे सगळे आम्ही GB10 साठी निवडले आणि ट्यून केले. वेट सुमारे 20 GB घेतात, आणि चालू असताना मशीनची सुमारे 38 GB मेमरी मोकळी राहते.

तुमचा कोड तुमच्या डेस्कवरच ठेवा

कोड जिथे लिहिला गेला त्याच टेबलावर राहिला पाहिजे असे तुम्हाला वाटत असेल, तर GitHub वर रिपॉझिटरीला स्टार द्या. अशाच प्रकारे इतर GB10 मालकांना Mightling सापडते.
