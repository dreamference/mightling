1.7.0 मध्ये आणखी: Night Shift एखादा टास्क अनेक वेळा करून पाहून सर्वोत्तम प्रयत्न ठेवू शकतो (/night add --best-of N), एक मशीन अनेक Signal ब्रिज चालवू शकते, आणि क्लायंट एकाच नेटवर्कवरील दोन नोडमधून निवडू शकतो, आधीपासून माहीत असलेला नोड न गमावता. रिलीझ नोट्स आणि डाउनलोड.

इन्स्टॉल

$ curl -fsSL https://github.com/dreamference/mightling/releases/latest/download/install.sh | bash
$ ling-admin server start      # मॉडेल एकदाच डाउनलोड होते (~20 GB), मग सुरू होते
$ cd ~/your-project && ling    # झाले, एवढेच

NVIDIA DGX Spark आणि प्रत्येक GB10 मशीनवर चालते. स्क्रिप्ट प्रत्येक डाउनलोड रिलीझच्या चेकसमशी पडताळते आणि प्रत्येक sudo कमांड चालवण्यापूर्वी ती दाखवते. हवे असल्यास आधी ती वाचा.

Mac आणि Linux क्लायंट

तुमचे इतर कॉम्प्युटर लोकल नेटवर्कवरून GB10 चे मॉडेल वापरतात. Mac किंवा दुसऱ्या Linux मशीनवर वरचीच कमांड ling क्लायंट इन्स्टॉल करते; तो GB10 स्वतःहून शोधतो.

1.7.2 पासून ती Mac वर डेस्कटॉप ॲपही Applications मध्ये ठेवते, उघडायला तयार (--no-app ने ते वगळता येते).

Windows क्लायंट प्रिव्ह्यू

> irm https://github.com/dreamference/mightling/releases/latest/download/install.ps1 | iex

PowerShell मध्ये. प्रशासक अधिकारांशिवाय इन्स्टॉल होते (1.7.2 पासून डेस्कटॉप ॲपही), मग Windows एकदा एजंटचा सँडबॉक्स सेट करायला सांगते. अजून साइन केलेले नाही, म्हणून Smart App Control बंद असायला हवे. स्क्रिप्ट वाचा.

इन्स्टॉल करण्याचे इतर मार्ग

रिलीझ पेजवर Mac चे dmg (Mightling-<version>-arm64-preview.dmg, Intel साठी x64) आणि Windows इन्स्टॉलर (Mightling-Setup-<version>-x64.exe, किंवा arm64) देखील आहेत. हे साइन न केलेले प्रिव्ह्यू आहेत: ब्राउझरमधून डाउनलोड केल्यास पहिल्यांदा थांबवले जातात. आधी प्रत्येक फाइल रिलीझच्या साइन केलेल्या SHA256SUMS शी तपासा.

  • macOS 15 आणि नंतरचे: Mightling ला Applications मध्ये ओढा आणि एकदा उघडा, मग System Settings › Privacy & Security › Open Anyway. macOS 14 आणि जुन्यामध्ये ॲपवर Control-क्लिक करा › Open.
  • Windows: SmartScreen › More info › Run anyway. Smart App Control बंद असायला हवे.

आधी हे करून पहा

किंवा आज रात्रीसाठी काम रांगेत लावा: /night add <task>. तुम्ही झोपलेले असताना Mightling रांग संपवते, प्रत्येक टास्क स्वतःच्या git ब्रांचवर, आणि सकाळी चहा पिताना तुम्ही ब्रांच तपासता.

$ ling "explain this repository to me like I'm new on the team"
# reads the code index (ling-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ling "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ling-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

🧭 कोड इंडेक्स

तुमच्या रिपॉझिटरीत डेफिनिशन्स, कॉलर आणि परिणाम, म्हणजे एजंट कोडसाठी grep करण्याऐवजी तो थेट शोधतो.

🔎 वेब सर्च आणि फेच

तुमच्या स्वतःच्या मशीनवरील खाजगी SearXNG मार्फत: सर्च अकाउंट नाही, API की नाही.

🌙 Night Shift

झोपण्यापूर्वी /night add <task>; सकाळपर्यंत प्रत्येक टास्क स्वतःच्या git ब्रांचवर पूर्ण. तुमच्याशिवाय काहीही मर्ज किंवा पुश होत नाही.

तुम्हाला काय मिळते

Mightling 1.7.0 चे डेस्कटॉप ॲप Ask आणि Work एकाच विंडोत ठेवते. Work म्हणजे एजंट सेशनसाठी पूर्ण वर्कबेंच: फाइल, स्किल आणि कमांड असलेला कंपोझर, स्टेज, रिव्हर्ट आणि कमिट करण्यासाठी रिव्ह्यू पेन, वर्कट्री, टर्मिनल टॅब, आणि थ्रेडच्या शेजारी फाइल ट्री व फाइल टॅब. तुमच्या इतर कॉम्प्युटरवर ते तुमच्या GB10 चे क्लायंट म्हणून चालते आणि त्याला लोकल नेटवर्कवर शोधते.

🪟 डेस्कटॉप ॲप प्रिव्ह्यू

Ask आणि Work एका विंडोत, GB10, Mac, Linux किंवा Windows वर: मंजुरीसह एजंट सेशन, रिव्ह्यू पेन, वर्कट्री आणि अनडू. 1.7 मध्ये नवे.

वेब सर्च, इमेज सर्च आणि डिक्टेशनसह प्रश्न, आणि तुमचे एजंट सेशन, याच मशीनवरून किंवा जोडलेल्या फोनवरून, त्याच लोकल मॉडेलवर.

डॉक्स →

macOS प्रिव्ह्यू

1.7.2 पासून इन्स्टॉल कमांड Mightling ला ling सोबत Applications मध्ये ठेवते, आणि ते इतर कोणत्याही ॲपप्रमाणे उघडते. Apple silicon आणि Intel, macOS 12 किंवा नंतरचे. ling update ते अपडेट करते.

Linux

GB10 वर mightling_1.7.2_arm64.deb ॲप, त्याची लाँचर एंट्री आणि ling-app कमांड इन्स्टॉल करते, सोबत त्याला लागणारा सँडबॉक्स प्रोफाइल:

$ sudo apt install ./mightling_1.7.2_arm64.deb

मग ते ॲप्लिकेशन मेनूमधून उघडा, किंवा ling app ने. अधिक.

Windows 11 प्रिव्ह्यू

1.7.2 पासून PowerShell ची ओळ ॲपही इन्स्टॉल करते, फक्त तुमच्यासाठी आणि प्रशासक अधिकारांशिवाय, Start मेनू एंट्रीसह; Settings → Apps मधून ते काढता येते; ling update ते अपडेट करते. Smart App Control बंद असायला हवे.

ling-admin mcp · ling signal · ling chat

JetBrains, VS Code आणि तुमचा फोन

stdio MCP (ling-admin mcp) द्वारे JetBrains किंवा VS Code जोडा, किंवा Signal (Note to Self), Telegram (Mini App रिपॉझिटरी वर्कबेंचसह) आणि Tailscale वरील Matrix वरून तुमच्या GB10 ला संदेश पाठवा. तुम्ही चालू करेपर्यंत प्रत्येक फोन ब्रिज बंद राहतो.

डॉक्स →
$ ling-admin mcp            # stdio MCP for JetBrains and VS Code
$ ling signal setup         # Note to Self only, off until linked
$ ling chat telegram setup  # topics and the Mini App

📬 Gmail, Drive, Calendar प्रिव्ह्यू

रीड-ओन्ली, तुमच्या मशीनवरच राहणाऱ्या साइन-इनमधून. /airgapped on वर पूर्णपणे बंद.

तुमचा कोड तुमच्या डेस्कबाहेर जात नाही, आणि तुम्ही ते सिद्ध करू शकता

क्लाउड कोडिंग एजंट तुमचा सोर्स कोड दुसऱ्याच्या सर्व्हरवर पाठवतात. Mightling तो कुठेही पाठवत नाही: मॉडेल तुमच्या GB10 वर चालते, आणि Mightling मधले काहीही बाहेर संपर्क साधत नाही. वापराचे विश्लेषण नाही, मेट्रिक्स नाहीत, साइन-इन नाही, "अनामिक" क्रॅश रिपोर्ट नाहीत. त्यामुळे अपलोड करण्याची परवानगी नसलेल्या कोडसाठी ते वापरता येते: क्लायंटचे काम, नियंत्रित डेटा, अप्रकाशित उत्पादने.

एक कमांड strace खाली खऱ्या Mightling सेशनला चालवते आणि त्याने केलेल्या प्रत्येक नेटवर्क कनेक्शनची यादी देते:

$ ling-admin audit egress
✔ Egress audit: pass
Network destinations:
   127.0.0.1:8000     29x  model server
   127.0.0.1:8767      1x  Gmail search service
DNS queries: none
Networked git commands: none

सगळे काही 127.0.0.1 वरच राहिले. एकही DNS लुकअप नाही.

पक्की हमी हवी?

/airgapped on लिहा, आणि एजंट चालवत असलेल्या प्रत्येक कमांडला Linux कर्नलकडून रिकामा नेटवर्क नेमस्पेस मिळतो. ही मॉडेलला केलेली नम्र विनंती नाही: पोहोचायला नेटवर्कच नाही. सँडबॉक्स टाळणारे Full Access त्याच वेळी नाकारले जाते.

काय बाहेर जाऊ शकते, आणि कधी

फक्त तुम्ही किंवा एजंट जे मागतो तेच: वेब सर्च (तुमच्या स्वतःच्या मशीनवरील खाजगी SearXNG मार्फत), पेज फेच, तुम्ही जोडलेल्या Google अकाउंटला रीड-ओन्ली विनंती, किंवा अपडेट तपासणी. /airgapped on वर यापैकी काहीही नाही.

≈69% चा अंदाज कसा काढला

100 टास्क म्हणजे Verified चा पाचवा भाग, म्हणून संपूर्ण सेटचा आकडा हा अंदाज आहे. सर्व 175 सार्वजनिक Verified सबमिशनच्या प्रति-टास्क निकालांवर एक एक-पॅरामीटर आयटम-रिस्पॉन्स (Rasch) मॉडेल बसवले आहे: प्रत्येक टास्कला एक काठिण्य आणि प्रत्येक सिस्टमला एक क्षमता. Mightling ची क्षमता ती आहे जी या 100 टास्कवर 68 सोडवले जाणे स्पष्ट करते; ≈69% म्हणजे त्या क्षमतेचा सर्व 500 वर अपेक्षित स्कोअर (प्रकाशित स्कोअरवरचे साधे रिग्रेशन एका गुणाच्या आत सहमत आहे). तपासण्यासाठी प्रत्येक सार्वजनिक सबमिशन फक्त याच 100 टास्कवर स्कोअर केले आणि त्याच पद्धतीने त्याचा एकूण स्कोअर वर्तवला: त्रुटी 2.4 गुण (RMSE) होती, आणि वरचा पट्टा त्याच्या ±1.96 पट आहे. तक्त्यातील प्रत्येक आकडा scripts/swe_bench_compare.py ने SWE-bench/experiments च्या सार्वजनिक प्रति-टास्क डेटावरून पुन्हा मिळवता येतो.

FAQ

मला GB10 लागेल का?

हो, मॉडेल चालवण्यासाठी. तुमचे इतर कॉम्प्युटर त्याचे क्लायंट म्हणून चालतात: Linux (Arm किंवा x86) आणि macOS त्याच इन्स्टॉल कमांडने, Windows (Arm किंवा x86, प्रिव्ह्यू) PowerShell च्या ओळीने.

मी Puffin इन्स्टॉल केले होते. हेच ते आहे का?

हो: 1.5 मध्ये Puffin चे नाव बदलून Mightling झाले. एकदा puffin update चालवा, मग शेवटचे एकदा puffin. ते तुमचे सेशन, सेटिंग आणि लिंक नव्या नावाखाली हलवते, आणि त्यानंतर कमांड ling आहे.

ते खरंच मोफत आहे का?

हो. Mightling AGPL अंतर्गत ओपन सोर्स आहे, आणि मॉडेलचे वेट्स मोफत आहेत. तुमचा एकमेव चालू खर्च वीज आहे.

मशीनशिवाय आणखी काय लागते?

त्यासोबत येणारी OS (DGX OS 7, किंवा जिथे विक्रेता देतो तिथे Ubuntu 24.04), NVIDIA Container Toolkit सह Docker, Python 3 आणि Git. साध्या Ubuntu वर ling-admin host check काय कमी आहे ते सांगते.

काही कधी इंटरनेटपर्यंत पोहोचते का?

फक्त तुम्ही किंवा एजंट जे मागता तेच, जसे तुमच्या स्वतःच्या मशीनवरील SearXNG मार्फत वेब सर्च, आणि पहिल्यांदाचे डाउनलोड. /airgapped on हे सगळे बंद करते.

ते कोणते मॉडेल चालवते?

NVIDIA च्या 4-बिट NVFP4 फॉरमॅटमधील Qwen3.8-27B, SGLang वर DFlash2 ड्राफ्टरसह, GB10 साठी निवडलेले आणि ट्यून केलेले. सुमारे 20 GB चे वेट्स; सर्व्ह करताना मशीनची सुमारे 38 GB मेमरी मोकळी राहते.
