v1.7.0 →

1.7.0-তে আরও: Night Shift একটি টাস্ক কয়েকবার চেষ্টা করে সেরা প্রচেষ্টাটি রাখতে পারে (/night add --best-of N), একটি মেশিন একাধিক Signal ব্রিজ চালাতে পারে, এবং ক্লায়েন্ট একই নেটওয়ার্কের দুটি নোডের মধ্য থেকে বেছে নিতে পারে, যে নোডকে আগে থেকে চেনে তাকে না হারিয়ে। রিলিজ নোট ও ডাউনলোড।

ইনস্টল

$ curl -fsSL https://github.com/dreamference/mightling/releases/latest/download/install.sh | bash
$ ling-admin server start      # মডেল একবারই ডাউনলোড হয় (~20 GB), তারপর চালু হয়ে যায়
$ cd ~/your-project && ling    # ব্যস, এটুকুই

NVIDIA DGX Spark এবং প্রতিটি GB10 মেশিনে কাজ করে। স্ক্রিপ্ট প্রতিটি ডাউনলোড রিলিজের চেকসামের সঙ্গে মিলিয়ে দেখে এবং প্রতিটি sudo কমান্ড চালানোর আগে সেটি দেখিয়ে দেয়। চাইলে আগে সেটি পড়ে নিন।

Mac ও Linux ক্লায়েন্ট

আপনার অন্য কম্পিউটারগুলো লোকাল নেটওয়ার্কে GB10-এর মডেল ব্যবহার করে। Mac বা অন্য কোনো Linux মেশিনে উপরের একই কমান্ড ling ক্লায়েন্ট ইনস্টল করে; এটি নিজেই GB10 খুঁজে নেয়।

1.7.2 থেকে এটি Mac-এ ডেস্কটপ অ্যাপও Applications-এ রেখে দেয়, খোলার জন্য তৈরি (--no-app দিলে বাদ যায়)।

Windows ক্লায়েন্ট প্রিভিউ

> irm https://github.com/dreamference/mightling/releases/latest/download/install.ps1 | iex

PowerShell-এ। অ্যাডমিনিস্ট্রেটর অধিকার ছাড়াই ইনস্টল হয় (1.7.2 থেকে ডেস্কটপ অ্যাপও), তারপর Windows একবার এজেন্টের স্যান্ডবক্স সেট করতে বলে। এখনও সাইন করা হয়নি, তাই Smart App Control বন্ধ থাকতে হবে। স্ক্রিপ্ট পড়ুন।

ইনস্টল করার অন্যান্য উপায়

রিলিজ পেজে Mac-এর dmg (Mightling-<version>-arm64-preview.dmg, Intel-এর জন্য x64) এবং Windows ইনস্টলারও (Mightling-Setup-<version>-x64.exe, বা arm64) আছে। এগুলো সাইন-না-করা প্রিভিউ: ব্রাউজারে ডাউনলোড করলে প্রথমবার আটকে দেওয়া হয়। আগে প্রতিটিকে রিলিজের সাইন করা SHA256SUMS-এর সঙ্গে মিলিয়ে নিন।

  • macOS 15 ও পরবর্তী: Mightling-কে Applications-এ টেনে নিয়ে একবার খুলুন, তারপর System Settings › Privacy & Security › Open Anyway। macOS 14 ও আগের সংস্করণে অ্যাপে Control-ক্লিক করুন › Open।
  • Windows: SmartScreen › More info › Run anyway। Smart App Control বন্ধ থাকতে হবে।

আগে এগুলো চেষ্টা করুন

অথবা আজ রাতের জন্য কাজ সারিতে দিন: /night add <task>। আপনি ঘুমানোর সময় Mightling সারিটি শেষ করে, প্রতিটি টাস্ক তার নিজস্ব git ব্রাঞ্চে, আর সকালে চা খেতে খেতে আপনি ব্রাঞ্চগুলো দেখে নেন।

$ ling "explain this repository to me like I'm new on the team"
# reads the code index (ling-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ling "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ling-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

আপনি কী পাচ্ছেন

Mightling 1.7.0-এর ডেস্কটপ অ্যাপ Ask ও Work-কে একই উইন্ডোতে রাখে। Work হলো এজেন্ট সেশনের পূর্ণাঙ্গ ওয়ার্কবেঞ্চ: ফাইল, স্কিল ও কমান্ডসহ কম্পোজার, স্টেজ, রিভার্ট ও কমিট করার রিভিউ পেন, ওয়ার্কট্রি, টার্মিনাল ট্যাব, এবং থ্রেডের পাশে ফাইল ট্রি ও ফাইল ট্যাব। আপনার অন্য কম্পিউটারে এটি আপনার GB10-এর ক্লায়েন্ট হিসেবে কাজ করে এবং লোকাল নেটওয়ার্কে সেটিকে খুঁজে নেয়।

🪟 ডেস্কটপ অ্যাপ প্রিভিউ

Ask ও Work একই উইন্ডোতে, GB10, Mac, Linux বা Windows-এ: অনুমোদনসহ এজেন্ট সেশন, রিভিউ পেন, ওয়ার্কট্রি ও আনডু। 1.7-এ নতুন।

ওয়েব সার্চ, ইমেজ সার্চ ও ডিকটেশনসহ প্রশ্ন, এবং আপনার এজেন্ট সেশন, এই মেশিন থেকে বা পেয়ার করা ফোন থেকে, একই লোকাল মডেলে।

ডক্স →

macOS প্রিভিউ

1.7.2 থেকে ইনস্টল কমান্ড Mightling-কে ling-এর পাশে Applications-এ রেখে দেয়, আর এটি অন্য যেকোনো অ্যাপের মতোই খোলে। Apple silicon ও Intel, macOS 12 বা তার পরের সংস্করণ। ling update এটি আপডেট করে।

Linux

GB10-এ mightling_1.7.0_arm64.deb অ্যাপ, তার লঞ্চার এন্ট্রি ও ling-app কমান্ড ইনস্টল করে, সঙ্গে প্রয়োজনীয় স্যান্ডবক্স প্রোফাইল:

$ sudo apt install ./mightling_1.7.0_arm64.deb

তারপর অ্যাপ্লিকেশন মেনু থেকে খুলুন, অথবা ling app দিয়ে। আরও।

Windows 11 প্রিভিউ

1.7.2 থেকে PowerShell-এর লাইন অ্যাপটিও ইনস্টল করে, শুধু আপনার জন্য এবং অ্যাডমিনিস্ট্রেটর অধিকার ছাড়াই, Start মেনু এন্ট্রিসহ; Settings → Apps থেকে সরানো যায়; ling update এটি আপডেট করে। Smart App Control বন্ধ থাকতে হবে।

ling-admin mcp · ling signal · ling chat

JetBrains, VS Code এবং আপনার ফোন

stdio MCP (ling-admin mcp) দিয়ে JetBrains বা VS Code যুক্ত করুন, অথবা Signal (Note to Self), Telegram (Mini App রিপোজিটরি ওয়ার্কবেঞ্চসহ) ও Tailscale-এ Matrix থেকে আপনার GB10-এ বার্তা পাঠান। আপনি চালু না করা পর্যন্ত প্রতিটি ফোন ব্রিজ বন্ধ থাকে।

ডক্স →
$ ling-admin mcp            # stdio MCP for JetBrains and VS Code
$ ling signal setup         # Note to Self only, off until linked
$ ling chat telegram setup  # topics and the Mini App

আপনার কোড আপনার ডেস্কের বাইরে যায় না, আর আপনি তা প্রমাণ করতে পারেন

ক্লাউড কোডিং এজেন্ট আপনার সোর্স কোড অন্য কারও সার্ভারে পাঠায়। Mightling তা কোথাও পাঠায় না: মডেল আপনার GB10-এ চলে, আর Mightling-এর কিছুই বাইরে খবর পাঠায় না। কোনো ব্যবহার-বিশ্লেষণ নেই, মেট্রিক্স নেই, সাইন-ইন নেই, "বেনামি" ক্র্যাশ রিপোর্ট নেই। তাই যে কোড আপলোড করার অনুমতি নেই তাতেও এটি ব্যবহার করা যায়: ক্লায়েন্টের কাজ, নিয়ন্ত্রিত ডেটা, অপ্রকাশিত পণ্য।

একটি কমান্ড strace-এর অধীনে একটি আসল Mightling সেশন চালায় এবং এটি যতগুলো নেটওয়ার্ক কানেকশন করেছে সবগুলোর তালিকা দেয়:

/airgapped on লিখুন, আর এজেন্ট যে কমান্ডই চালায় তাকে Linux কার্নেল থেকে একটি ফাঁকা নেটওয়ার্ক নেমস্পেস দেওয়া হয়। এটি মডেলের কাছে ভদ্র অনুরোধ নয়: পৌঁছানোর মতো কোনো নেটওয়ার্কই নেই। স্যান্ডবক্স এড়িয়ে যেত যে Full Access, সেটিও একই সময়ে প্রত্যাখ্যাত হয়।

SWE-bench Verified, একটি DGX Spark-এ মাপা

2026-10-08 তারিখে Mightling 1.5.1-এর এজেন্ট Qwen3.8-27B সহ একটি DGX Spark-এ, অফলাইনে, SWE-bench Verified-এর 100টির মধ্যে 68টি টাস্ক সমাধান করেছে: 100টি টাস্কের একটি নির্দিষ্ট নমুনা, প্রতি টাস্কে একটি চেষ্টা, ডিফল্ট মোড। সব 500টি টাস্কে স্কেল করলে এটি আনুমানিক ≈69% (95% পরিসর 63.9–73.4%)। এটি আমাদের নিজের মেশিনে, একটি উপসেটে, আমাদের নিজস্ব পরিমাপ, লিডারবোর্ডের এন্ট্রি নয়।

একে সমমানের মডেলের তুলনা হিসেবে দেখুন, র‍্যাঙ্কিং হিসেবে নয়। একই 100টি টাস্কে Mightling Qwen3-Coder-480B ও GLM-4.6-এর সমান টাস্ক সমাধান করেছে, যে মডেলগুলো তার চেয়ে বহুগুণ বড়, কিন্তু প্রতিটি সারিতে এজেন্ট আলাদা, হার্ডওয়্যার আলাদা, আর লিডারবোর্ডের সারিগুলোতে অফিশিয়াল x86 টেস্ট ইমেজ, যেখানে আমাদের রান হয়েছে কমিউনিটির arm64 ইমেজে। refine মোডে প্রথম সেশন কিছু না বদলে টাস্কটি বুঝে নেয় এবং নতুন একটি সেশন সেটি করে: এটি ডিফল্টের চেয়ে একটি টাস্ক বেশি সমাধান করেছে (68-এর বিপরীতে 69, প্রতিটি মোড এমন কিছু টাস্ক জিতেছে যা অন্যটি হারিয়েছে), প্রতি টাস্কে প্রায় 2.2 গুণ সময়ে, তাই এটি ঐচ্ছিকই থাকছে (ling --refine)।

≈69% কীভাবে অনুমান করা হয়েছে

100টি টাস্ক Verified-এর এক-পঞ্চমাংশ, তাই পুরো সেটের সংখ্যাটি একটি অনুমান। সব 175টি সর্বজনীন Verified সাবমিশনের প্রতি-টাস্ক ফলাফলে একটি এক-প্যারামিটার আইটেম-রেসপন্স (Rasch) মডেল ফিট করা হয়েছে: প্রতিটি টাস্কের একটি কাঠিন্য এবং প্রতিটি সিস্টেমের একটি সামর্থ্য। Mightling-এর সামর্থ্য সেটি, যা এই 100টি টাস্কে 68টি সমাধান হওয়াকে ব্যাখ্যা করে; ≈69% হলো সেই সামর্থ্যের সব 500টিতে প্রত্যাশিত স্কোর (প্রকাশিত স্কোরের ওপর সাধারণ রিগ্রেশন এক পয়েন্টের মধ্যে একমত)। যাচাই করতে প্রতিটি সর্বজনীন সাবমিশনকে শুধু এই 100টি টাস্কে স্কোর করা হয়েছে এবং একইভাবে তার সামগ্রিক স্কোরের পূর্বাভাস দেওয়া হয়েছে: ত্রুটি ছিল 2.4 পয়েন্ট (RMSE), আর ওপরের পরিসর তার ±1.96 গুণ। সারণির প্রতিটি সংখ্যা scripts/swe_bench_compare.py দিয়ে SWE-bench/experiments-এর সর্বজনীন প্রতি-টাস্ক ডেটা থেকে পুনরুৎপাদন করা যায়।

এই 100টি টাস্ক Verified-এর রিপোজিটরিগুলোর মধ্যে পুরো সেটের অনুপাতে ছড়ানো, সেই টাস্কগুলো থেকে যাদের টেস্ট এনভায়রনমেন্ট arm64-এ চলে ও যাচাই হয় (গোল্ড প্যাচ পাস করে, খালি পরিবর্তন ফেল করে)। প্রকাশিত সিস্টেমগুলো এই 100টিতে সব 500টির চেয়ে 1.0 থেকে 1.5 পয়েন্ট কম স্কোর করে, তাই নমুনাটি সহজ নয়। এটি লিডারবোর্ডের এন্ট্রি নয়: সেগুলোর গ্রেডিং SWE-bench টিম নিজেদের অবকাঠামোয় করে।

  12. Cursor নিজস্ব বেঞ্চমার্ক Cursor Bench-এর ফল প্রকাশ করে, SWE-bench Verified-এর নয়। সূত্র: Cursor ব্লগ, Composer।

লিডারবোর্ডের সব সংখ্যা: swebench.com এবং SWE-bench/experiments রিপোজিটরি; "একই 100টি টাস্ক" মানে প্রতিটি সাবমিশনের প্রকাশিত প্রতি-টাস্ক ফল, শুধু Mightling যে টাস্কগুলো চালিয়েছে সেগুলোর মধ্যে সীমিত।

FAQ

আমার কি GB10 লাগবে?

হ্যাঁ, মডেল চালানোর জন্য। আপনার অন্য কম্পিউটারগুলো এর ক্লায়েন্ট হিসেবে কাজ করে: Linux (Arm বা x86) ও macOS একই ইনস্টল কমান্ডে, Windows (Arm বা x86, প্রিভিউ) PowerShell-এর লাইনে।

আমি Puffin ইনস্টল করেছিলাম। এটাই কি সেটা?

হ্যাঁ: 1.5-এ Puffin-এর নাম বদলে Mightling হয়েছে। একবার puffin update চালান, তারপর শেষবারের মতো puffin। এটি আপনার সেশন, সেটিংস ও লিঙ্ক নতুন নামে সরিয়ে আনে, এবং তারপর থেকে কমান্ড ling।

এটা কি সত্যিই বিনামূল্যে?

হ্যাঁ। Mightling AGPL-এর অধীনে ওপেন সোর্স, আর মডেলের ওয়েটগুলো বিনামূল্যে। আপনার একমাত্র চলমান খরচ বিদ্যুৎ।

মেশিন ছাড়া আর কী লাগবে?

মেশিনের সঙ্গে আসা OS (DGX OS 7, অথবা যেখানে বিক্রেতা দেয় সেখানে Ubuntu 24.04), NVIDIA Container Toolkit সহ Docker, Python 3 ও Git। সাধারণ Ubuntu-তে ling-admin host check বলে দেয় কী কম আছে।

কিছু কি কখনো ইন্টারনেটে পৌঁছায়?

শুধু যা আপনি বা এজেন্ট চায়, যেমন আপনার নিজের মেশিনের SearXNG দিয়ে ওয়েব সার্চ, এবং প্রথমবারের ডাউনলোড। /airgapped on এসব বন্ধ করে দেয়।

এটি কোন মডেল চালায়?

NVIDIA-এর 4-বিট NVFP4 ফরম্যাটে Qwen3.8-27B, SGLang-এ DFlash2 ড্রাফটারসহ, GB10-এর জন্য বাছাই ও টিউন করা। প্রায় 20 GB ওয়েট; সার্ভ করার সময় মেশিনের প্রায় 38 GB মেমরি খালি থাকে।

আপনার কোড আপনার ডেস্কেই রাখুন

কোড যে ডেস্কে লেখা হয়েছে সেখানেই থাকা উচিত বলে মনে করলে রিপোজিটরিতে স্টার দিন: এভাবেই অন্য GB10 মালিকরা Mightling খুঁজে পান।
