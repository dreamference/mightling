v1.7.0 →

1.7.0-এ আরও আছে: Night Shift একটি কাজ কয়েকবার চেষ্টা করে সেরা চেষ্টাটি রাখতে পারে (/night add --best-of N)। একটি মেশিন কয়েকটি Signal ব্রিজ চালাতে পারে। আর একই নেটওয়ার্কে দুটি GB10 দেখতে পাওয়া কম্পিউটার আগে চেনা মেশিনটি না ভুলেই দুটির মধ্যে বেছে নিতে পারে। রিলিজ নোট ও ডাউনলোড।

ইনস্টল

$ curl -fsSL https://github.com/dreamference/mightling/releases/latest/download/install.sh | bash
$ ling-admin server start      # মডেলটি একবার ডাউনলোড করে (~20 GB), তারপর চালু করে
$ cd ~/your-project && ling    # ব্যস, এটুকুই

এটি NVIDIA DGX Spark-এ এবং অন্য যেকোনো GB10 মেশিনে কাজ করে। স্ক্রিপ্ট প্রতিটি ডাউনলোড রিলিজের চেকসামের সঙ্গে মিলিয়ে দেখে, আর প্রতিটি sudo কমান্ড চালানোর আগে আপনাকে দেখিয়ে দেয়। চাইলে আগে স্ক্রিপ্টটি পড়ে নিতে পারেন।

Mac ও Linux ক্লায়েন্ট

আপনার অন্য কম্পিউটারগুলো বাড়ি বা অফিসের নেটওয়ার্কে GB10-এর মডেল ধার নেয়। Mac বা অন্য Linux মেশিনে একই কমান্ড ling ইনস্টল করে, যেটিতে আপনি টাইপ করেন। এটি নিজেই GB10 খুঁজে নেয়।

1.7.2 থেকে এটি Mac-এ ডেস্কটপ অ্যাপটিও Applications-এ রেখে দেয়, খোলার জন্য তৈরি। না চাইলে --no-app যোগ করুন।

Windows ক্লায়েন্ট প্রিভিউ

> irm https://github.com/dreamference/mightling/releases/latest/download/install.ps1 | iex

এটি PowerShell-এ টাইপ করুন। এতে অ্যাডমিনিস্ট্রেটর অধিকার লাগে না (1.7.2 থেকে ডেস্কটপ অ্যাপের জন্যও তা-ই)। তারপর Windows আপনাকে একবার জিজ্ঞেস করে একটি বন্ধ জায়গা তৈরি করতে, যেখানে সহায়ক কমান্ড চালায়। ইনস্টলার এখনও সাইন করা নয়, তাই Smart App Control বন্ধ থাকতে হবে। স্ক্রিপ্টটি পড়ুন।

ইনস্টল করার অন্যান্য উপায়

রিলিজ পাতায় Mac-এর ডিস্ক ইমেজও আছে (Mightling-<version>-arm64-preview.dmg, Intel-এর জন্য x64) এবং Windows ইনস্টলার (Mightling-Setup-<version>-x64.exe, অথবা arm64)। এগুলো সাইন-না-করা প্রিভিউ, তাই ব্রাউজারে ডাউনলোড করলে আপনার সিস্টেম প্রথমবার এগুলো থামিয়ে দেয়। কোনোটি খোলার আগে রিলিজের সাইন করা SHA256SUMS ফাইলের সঙ্গে মিলিয়ে নিন।

  • macOS 15 ও পরের সংস্করণ: Mightling-কে Applications-এ টেনে নিন এবং একবার খুলুন। তারপর System Settings › Privacy & Security-এ গিয়ে Open Anyway চাপুন। macOS 14 ও আগের সংস্করণে অ্যাপের ওপর Control-ক্লিক করে Open বেছে নিন।
  • Windows: SmartScreen › More info › Run anyway। Smart App Control বন্ধ থাকতে হবে।

আগে এগুলো চেষ্টা করুন

অথবা /night add <task> দিয়ে আজ রাতের জন্য কাজ রেখে যান। আপনি ঘুমানোর সময় Mightling তালিকা ধরে এগোয়, প্রতিটি কাজ নিজস্ব git ব্রাঞ্চে, আর সকালে আপনি ব্রাঞ্চগুলো দেখে নেন।

$ ling "explain this repository to me like I'm new on the team"
# reads the code index (ling-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ling "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ling-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

সার্চ চলে আপনার নিজের মেশিনের একটি ব্যক্তিগত SearXNG দিয়ে, তাই সার্চের অ্যাকাউন্ট বা পাওয়ার মতো কোনো কী লাগে না। তবে উত্তর পেতে প্রশ্নগুলো ওয়েবে যায়।

🌙 Night Shift

ঘুমানোর আগে /night add <task> লিখুন। সকালে প্রতিটি কাজ নিজস্ব git ব্রাঞ্চে করা থাকে। আপনি না করলে কিছু মার্জ বা পুশ হয় না।

আপনি কী পাচ্ছেন

1.7.0-এর ডেস্কটপ অ্যাপ Mightling ব্যবহারের দুটি পথ এক উইন্ডোতে আনে: Ask, যেখানে আপনি প্রশ্ন করেন, আর Work, যেখানে সহায়ক আপনার কোড এডিট করে। Work-এ আছে কাজ লেখার একটি বাক্স (ফাইল, স্কিল ও কমান্ড জুড়ে দেওয়া যায়), রাখা বা ফিরিয়ে নেওয়ার আগে পরিবর্তন দেখার একটি প্যান, আপনার কোডের আলাদা কাজের কপি (worktrees), টার্মিনাল ট্যাব, আর কথোপকথনের পাশে একটি ফাইল ট্রি। আপনার অন্য কম্পিউটারে অ্যাপটি আপনার GB10-এর সঙ্গে কথা বলে, যেটি সে আপনার নেটওয়ার্কে খুঁজে নেয়।

🪟 ডেস্কটপ অ্যাপ প্রিভিউ

Ask ও Work এক উইন্ডোতে, GB10, Mac, Linux বা Windows-এ। সহায়কের সেশন আপনার অনুমতি চায়, আর আছে পরিবর্তন দেখার একটি প্যান, আলাদা কাজের কপি এবং আনডু। 1.7-এ নতুন।

ওয়েব সার্চ, ছবি সার্চ আর টাইপের বদলে কথা বলে প্রশ্ন, এবং আপনার সহায়ক সেশনও, এই মেশিন থেকে বা এর সঙ্গে জোড়া ফোন থেকে। সবই আপনার মেশিনের একই মডেল ব্যবহার করে।

আপনার কোড আপনার ডেস্কেই থাকে, আর আপনি তা যাচাই করে দেখতে পারেন

ক্লাউডের কোডিং সহায়ক আপনার সোর্স কোড অন্য কারও কম্পিউটারে পাঠায়। Mightling তা কোথাও পাঠায় না। মডেল আপনার GB10-এ চলে, আর Mightling-এর কিছুই বাইরে যোগাযোগ করে না: ব্যবহারের গণনা নেই, পরিমাপ নেই, সাইন-ইন নেই, এমনকি "বেনামি" ক্র্যাশ রিপোর্টও নেই। তাই যে কোড আপলোড করার অনুমতি আপনার নেই, যেমন কোনো ক্লায়েন্টের কাজ, সুরক্ষিত ডেটা বা এখনও প্রকাশ না হওয়া পণ্য, তাতেও এটি ব্যবহার করতে পারেন।

একটি কমান্ড strace-এর অধীনে একটি আসল Mightling সেশন চালায়, যে টুল প্রোগ্রামের প্রতিটি কল লক্ষ করে, তারপর সেশনটি যে নেটওয়ার্ক সংযোগ খুলেছে তার প্রতিটি তালিকা করে:

পাকা নিশ্চয়তা চান?

/airgapped on লিখুন। তখন সহায়ক যে কমান্ডই চালায়, Linux কার্নেল তাকে একটি ফাঁকা নেটওয়ার্ক দেয়। এটি মডেলের কাছে ভদ্র অনুরোধ নয়। পৌঁছানোর মতো কোনো নেটওয়ার্কই নেই। একই সঙ্গে Full Access, যা স্যান্ডবক্স এড়িয়ে যেত, প্রত্যাখ্যাত হয়।

কী বাইরে যেতে পারে, এবং কখন

শুধু যা আপনি বা সহায়ক চান: একটি ওয়েব সার্চ (আপনার নিজের মেশিনে চলা একটি ব্যক্তিগত SearXNG দিয়ে, যদিও সার্চটি নিজে ওয়েবে যায়), একটি ওয়েব পেজ আনা, আপনার যুক্ত করা Google অ্যাকাউন্টে শুধু-পড়ার অনুরোধ, অথবা হালনাগাদ আছে কি না তার খোঁজ। /airgapped on দিলে এর কোনোটিই ঘটে না।

SWE-bench Verified, একটি DGX Spark-এ মাপা

SWE-bench Verified হলো ওপেন-সোর্স প্রোগ্রাম থেকে নেওয়া 500টি আসল সমস্যার একটি সংকলন। প্রতিটিতে সহায়ককে কোড বদলাতে হয়, যাতে টেস্ট পাস করে। 2026-10-08 তারিখে আমরা এর 100টি Mightling 1.5.1-কে দিয়েছি, Qwen3.8-27B মডেল ব্যবহার করে, ইন্টারনেট ছাড়া একটিমাত্র DGX Spark-এ। প্রতিটিতে সে একটি চেষ্টা পেয়েছে, ডিফল্ট মোডে, আর 100টির মধ্যে 68টি সমাধান করেছে। এটিকে 500টিতে বাড়িয়ে ধরলে আমাদের অনুমান প্রায় 69%, কয়েক পয়েন্ট এদিক-ওদিক হতে পারে (95% পরিসর 63.9 থেকে 73.4%)। এটি আমরা নিজেরা, নিজেদের মেশিনে, সমস্যাগুলোর একটি নমুনার ওপর মেপেছি। এটি সরকারি লিডারবোর্ডের এন্ট্রি নয়।

এই টেবিলটি পড়ুন কারা কাছাকাছি তা দেখার উপায় হিসেবে, র‍্যাঙ্কিং হিসেবে নয়। একই 100টি সমস্যায় Mightling ততগুলোই সমাধান করেছে, যতগুলো Qwen3-Coder-480B ও GLM-4.6 করেছে, যে মডেলগুলো তার চেয়ে বহুগুণ বড়। কিন্তু প্রতিটি সারিতে সহায়ক প্রোগ্রাম আলাদা, হার্ডওয়্যারও আলাদা, আর লিডারবোর্ডের সারিগুলো x86 কম্পিউটারের জন্য সরকারি টেস্ট ইমেজ ব্যবহার করেছে, আমাদেরটা চলেছে arm64-এর জন্য কমিউনিটি ইমেজে। দ্বিতীয় একটি মোডও আছে, নাম refine। প্রথম সেশন সমস্যাটি পড়ে কিন্তু কিছু বদলায় না, তারপর একটি নতুন সেশন কাজটা করে। এটি ডিফল্টের চেয়ে একটি বেশি সমস্যা সমাধান করেছে (69 বনাম 68, আর প্রতিটি মোড এমন কিছু সমস্যা সমাধান করেছে যা অন্যটি পারেনি), এবং প্রতিটি সমস্যায় সময় লেগেছে প্রায় 2.2 গুণ। তাই ling --refine দিয়ে না চাইলে এটি বন্ধ থাকে।

69% অনুমান আমরা কীভাবে করি

100টি সমস্যা Verified-এর পাঁচ ভাগের এক ভাগ, তাই 500টির সংখ্যাটি একটি অনুমান। আমরা এটি এভাবে করেছি। Verified-এর সব 175টি জনসমক্ষে জমা পড়া ফলাফল নিই, সমস্যা ধরে ধরে। একটি এক-প্যারামিটারের আইটেম-রেসপন্স (Rasch) মডেলে প্রতিটি সমস্যাকে একটি কঠিনতা আর প্রতিটি সিস্টেমকে একটি সক্ষমতা দিই। Mightling-এর সক্ষমতা হলো যেটি এই 100টি সমস্যায় 68টি সমাধান করবে, আর ওই সক্ষমতা 500টিতে প্রায় 69% পাবে। প্রকাশিত স্কোরের ওপর একটি সাধারণ রিগ্রেশনও এক পয়েন্টের মধ্যে একই কথা বলে। আমরা পদ্ধতিটি অন্যদের ওপরও যাচাই করেছি: প্রতিটি জনসমক্ষে জমা পড়া ফলাফলের জন্য শুধু এই 100টি সমস্যার স্কোর দিয়ে 500টির স্কোর অনুমান করেছি। ভুলটি ছিল 2.4 পয়েন্ট (RMSE), আর ওপরের পরিসর হলো তার 1.96 গুণ, দুই দিকেই। টেবিলের প্রতিটি সংখ্যা scripts/swe_bench_compare.py দিয়ে আবার বের করা যায়, SWE-bench/experiments-এর সমস্যাভিত্তিক প্রকাশ্য ডেটা থেকে।

আমরা 100টি সমস্যা Verified-এর প্রোগ্রামগুলোর মধ্যে পুরো সংকলনের অনুপাতেই ভাগ করেছি। সমস্যাগুলো নিয়েছি সেই সমস্যাগুলো থেকে, যাদের টেস্ট সেটআপ arm64-এ কাজ করে এবং যাচাই হয় (সঠিক সমাধান পাস করে, আর কিছু না করলে ফেল করে)। প্রকাশিত সিস্টেমগুলো এই 100টিতে 500টির চেয়ে 1.0 থেকে 1.5 পয়েন্ট কম পায়, তাই নমুনাটি সহজ নয়। তবুও এটি লিডারবোর্ডের এন্ট্রি নয়, কারণ SWE-bench দল সেগুলো নিজেদের মেশিনে মূল্যায়ন করে।

FAQ

আমার কি GB10 লাগবে?

হ্যাঁ, মডেলটি চালানোর জন্য। আপনার অন্য কম্পিউটারগুলো ক্লায়েন্ট, যারা সেটি ধার নেয়: একই ইনস্টল কমান্ডে Linux (Arm বা x86) ও macOS, আর PowerShell-এর লাইনে Windows (Arm বা x86, প্রিভিউ)।

আমি Puffin ইনস্টল করেছি। এটি কি একই প্রোগ্রাম?

হ্যাঁ। 1.5-এ Puffin-এর নাম বদলে Mightling হয়েছে। একবার puffin update চালান, তারপর শেষবারের মতো puffin চালান। এটি আপনার সেশন, সেটিংস ও লিংক সরিয়ে আনে, আর তারপর কমান্ড হয় ling।

সত্যিই কি কোনো খরচ নেই?

প্রোগ্রামের জন্য কিছু না, মডেলের জন্যও কিছু না। Mightling AGPL-এর অধীনে ওপেন সোর্স, আর মডেলের ওয়েট বিনামূল্যে ব্যবহার করা যায়। আপনি দেন মেশিনের দাম আর তার বিদ্যুতের খরচ।

মেশিন ছাড়া আর কী লাগবে?

সঙ্গে আসা অপারেটিং সিস্টেম (DGX OS 7, অথবা NVIDIA যেখানে দেয় সেখানে Ubuntu 24.04), NVIDIA Container Toolkit-সহ Docker, Python 3 আর Git। সাধারণ Ubuntu-তে ling-admin host check বলে দেয় কী কী নেই।

কখনো কি কিছু ইন্টারনেটে যায়?

শুধু যা আপনি বা সহায়ক চান, যেমন একটি ওয়েব সার্চ (আপনার নিজের মেশিনে চলা একটি SearXNG দিয়ে) আর প্রথমবার ব্যবহারের ডাউনলোড। /airgapped on দিলে এ সবই বন্ধ।

এটি কোন মডেল চালায়?

Qwen3.8-27B, NVIDIA-র NVFP4 নামের 4-বিট ফরম্যাটে, SGLang দিয়ে চালানো, সঙ্গে DFlash2 ড্রাফটার নামের একটি ছোট আন্দাজকারী সহায়ক। এর সবকিছু আমরা GB10-এর জন্য বেছেছি ও টিউন করেছি। ওয়েটে লাগে প্রায় 20 GB, আর চলার সময় মেশিনের প্রায় 38 GB মেমরি খালি থাকে।

আপনার কোড আপনার ডেস্কেই রাখুন

কোড যেখানে লেখা হয়েছে সেই ডেস্কেই থাকা উচিত বলে মনে করলে GitHub-এ রিপোজিটরিতে একটি স্টার দিন। এভাবেই অন্য GB10 মালিকেরা Mightling খুঁজে পান।
