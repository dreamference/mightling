Mac اور Linux کلائنٹس

آپ کے باقی کمپیوٹر گھر یا دفتر کے نیٹ ورک پر GB10 کا ماڈل ادھار لیتے ہیں۔ Mac یا کسی اور Linux مشین پر یہی کمانڈ ling انسٹال کرتی ہے، یعنی وہ حصہ جس میں آپ ٹائپ کرتے ہیں۔ یہ GB10 کو خود ڈھونڈ لیتا ہے۔

1.7.2 سے یہ ڈیسک ٹاپ ایپ کو Mac پر Applications میں بھی رکھ دیتا ہے، کھولنے کے لیے تیار۔ اگر آپ اسے نہیں چاہتے تو --no-app لگائیں۔

انسٹال کرنے کے دوسرے طریقے

ریلیز کے صفحے پر Mac کی ڈسک امیج (Mightling-<version>-arm64-preview.dmg، یا Intel کے لیے x64) اور Windows کا انسٹالر (Mightling-Setup-<version>-x64.exe، یا arm64) بھی ہے۔ یہ بغیر دستخط کے پریویو ہیں، اس لیے براؤزر میں ڈاؤن لوڈ کرنے پر آپ کا سسٹم انہیں پہلی بار روک دیتا ہے۔ کھولنے سے پہلے انہیں ریلیز کی دستخط شدہ SHA256SUMS فائل سے ملا لیں۔

  • macOS 15 اور بعد کے لیے: Mightling کو Applications میں گھسیٹیں اور ایک بار کھولیں۔ پھر System Settings › Privacy & Security میں جائیں اور Open Anyway دبائیں۔ macOS 14 اور پہلے کے لیے ایپ پر Control دبا کر کلک کریں اور Open چنیں۔
  • Windows: SmartScreen › More info › Run anyway۔ Smart App Control بند ہونا چاہیے۔

پہلے یہ آزمائیں

یا کام آج رات کے لیے چھوڑ دیں /night add <task> سے۔ Mightling آپ کے سونے کے دوران فہرست پر کام کرتا ہے، ہر ٹاسک اپنی git برانچ پر، اور صبح آپ برانچیں دیکھ لیتے ہیں۔

$ ling "explain this repository to me like I'm new on the team"
# reads the code index (ling-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ling "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ling-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

🔎 ویب سرچ اور صفحہ حاصل کرنا

سرچ آپ کی اپنی مشین پر نجی SearXNG کے ذریعے ہوتی ہے، اس لیے نہ سرچ اکاؤنٹ چاہیے نہ کوئی کلید لینی پڑتی ہے۔ سوال پھر بھی جواب کے لیے ویب پر جاتے ہیں۔

🌙 Night Shift

سونے سے پہلے /night add <task> ٹائپ کریں۔ صبح تک ہر ٹاسک اپنی git برانچ پر مکمل ہوتا ہے۔ کچھ بھی مرج یا پش نہیں ہوتا جب تک آپ خود نہ کریں۔

آپ کو کیا ملتا ہے

1.7.0 کی ڈیسک ٹاپ ایپ Mightling کو استعمال کرنے کے دونوں طریقے ایک ونڈو میں رکھتی ہے: Ask، جہاں آپ سوال پوچھتے ہیں، اور Work، جہاں مددگار آپ کا کوڈ بدلتا ہے۔ Work میں ٹاسک ٹائپ کرنے کا ایک خانہ ہے (آپ فائلیں، اسکلز اور کمانڈز جوڑ سکتے ہیں)، تبدیلیاں رکھنے یا واپس لینے سے پہلے دیکھنے کا ایک پین، آپ کے کوڈ کی الگ الگ ورکنگ کاپیاں (ورک ٹریز)، ٹرمینل ٹیبز، اور گفتگو کے ساتھ فائل ٹری۔ آپ کے باقی کمپیوٹروں پر ایپ آپ کے GB10 سے بات کرتی ہے، جسے وہ آپ کے نیٹ ورک پر خود ڈھونڈ لیتی ہے۔

ling · ling-code · ling-docs

🖥️ ling، آپ کے ٹرمینل میں مددگار

آپ کا پروجیکٹ پڑھتا ہے، کمانڈز اور ٹیسٹ چلاتا ہے، کوڈ میں ترمیم کرتا ہے، اور کسی بھی خطرے والی چیز سے پہلے آپ سے پوچھتا ہے۔

$ ling worktree on   # new sessions start in their own worktree
$ cd ~/your-project && ling
> /airgapped on      # no network for any command it runs
> /worktree apply    # bring the changes back to your checkout

SWE-bench Verified، ایک DGX Spark پر ناپا گیا

SWE-bench Verified اوپن سورس پروگراموں سے لیے گئے 500 حقیقی مسائل کا مجموعہ ہے۔ ہر مسئلے میں مددگار کو کوڈ اس طرح بدلنا ہوتا ہے کہ ٹیسٹ پاس ہو جائیں۔ 2026-10-08 کو ہم نے ان میں سے 100 مسائل Mightling 1.5.1 کو دیے، Qwen3.8-27B ماڈل کے ساتھ، ایک DGX Spark پر بغیر انٹرنیٹ کے۔ اسے ہر مسئلے پر ایک ہی کوشش ملی، ڈیفالٹ موڈ میں، اور اس نے 100 میں سے 68 حل کیے۔ اگر ہم اسے سارے 500 پر پھیلائیں تو ہمارا اندازہ تقریباً 69% ہے، چند پوائنٹ کم یا زیادہ (95% کی حد 63.9 سے 73.4% ہے)۔ یہ ہم نے خود، اپنی مشین پر، مسائل کے ایک نمونے پر ناپا ہے۔ یہ سرکاری لیڈر بورڈ کا اندراج نہیں ہے۔

ہم 69% کا اندازہ کیسے لگاتے ہیں

100 مسائل Verified کا پانچواں حصہ ہیں، اس لیے سارے 500 کا عدد ایک اندازہ ہے۔ ہم نے یہ یوں بنایا۔ Verified کی تمام 175 عوامی جمع کرائی گئی کوششوں کے نتائج لیں، مسئلہ بہ مسئلہ۔ ایک پیرامیٹر والے آئٹم-ریسپانس (Rasch) ماڈل سے ہر مسئلے کو ایک مشکل اور ہر نظام کو ایک صلاحیت دیں۔ Mightling کی صلاحیت وہ ہے جو ان 100 مسائل میں 68 حل کرے، اور تقریباً 69% وہ ہے جو یہ صلاحیت سارے 500 پر حاصل کرتی۔ شائع شدہ اسکورز پر سادہ ریگریشن ایک پوائنٹ کے اندر اتفاق کرتا ہے۔ ہم نے اس طریقے کو دوسروں پر بھی جانچا: ہر عوامی جمع کرائی گئی کوشش کے لیے ہم نے صرف ان 100 مسائل پر اس کا اسکور استعمال کر کے سارے 500 پر اس کا اسکور بتایا۔ غلطی 2.4 پوائنٹ (RMSE) تھی، اور اوپر کی حد ہر طرف اس کا 1.96 گنا ہے۔ جدول کا ہر عدد scripts/swe_bench_compare.py سے دہرایا جا سکتا ہے، SWE-bench/experiments کے عوامی مسئلہ وار ڈیٹا سے۔

ہم نے 100 مسائل کو Verified کے پروگراموں میں اسی تناسب سے بانٹا جس تناسب سے پورے مجموعے میں ہیں۔ ہم نے انہیں ان مسائل میں سے چنا جن کا ٹیسٹ سیٹ اپ arm64 پر چلتا ہے اور درست نکلتا ہے (صحیح حل پاس ہوتا ہے، اور کچھ نہ کرنا فیل ہوتا ہے)۔ شائع شدہ نظام ان 100 پر سارے 500 کے مقابلے میں 1.0 سے 1.5 پوائنٹ کم اسکور کرتے ہیں، اس لیے یہ نمونہ آسان نہیں ہے۔ پھر بھی یہ لیڈر بورڈ کا اندراج نہیں، کیونکہ SWE-bench ٹیم انہیں اپنی مشینوں پر جانچتی ہے۔

جی، ماڈل چلانے کے لیے۔ آپ کے باقی کمپیوٹر کلائنٹ ہیں جو اسے ادھار لیتے ہیں: Linux (Arm یا x86) اور macOS اسی انسٹال کمانڈ سے، اور Windows (Arm یا x86، پریویو) PowerShell کی لائن سے۔

میں نے Puffin انسٹال کیا تھا۔ کیا یہ وہی پروگرام ہے؟

جی۔ Puffin کا نام 1.5 میں Mightling رکھا گیا۔ ایک بار puffin update چلائیں، پھر آخری بار puffin چلائیں۔ یہ آپ کے سیشنز، سیٹنگز اور لنکس منتقل کر دیتا ہے، اور اس کے بعد کمانڈ ling ہے۔

کیا واقعی اس پر کچھ خرچ نہیں آتا؟

پروگرام یا ماڈل کے لیے کچھ نہیں۔ Mightling AGPL کے تحت اوپن سورس ہے، اور ماڈل کے ویٹس مفت استعمال کے لیے ہیں۔ آپ مشین کی قیمت اور اس کی بجلی کا خرچ دیتے ہیں۔

مشین کے علاوہ مجھے کیا چاہیے؟

وہ آپریٹنگ سسٹم جو ساتھ آتا ہے (DGX OS 7، یا Ubuntu 24.04 جہاں NVIDIA دیتا ہے)، NVIDIA Container Toolkit کے ساتھ Docker، Python 3 اور Git۔ سادہ Ubuntu پر ling-admin host check بتاتا ہے کہ کیا کم ہے۔

کیا کبھی کچھ انٹرنیٹ پر جاتا ہے؟

صرف وہ جو آپ یا مددگار مانگیں، جیسے ویب سرچ (آپ کی اپنی مشین پر چلنے والے SearXNG کے ذریعے) اور پہلی بار استعمال پر ڈاؤن لوڈ۔ /airgapped on کے ساتھ یہ سب بند ہو جاتا ہے۔

یہ کون سا ماڈل چلاتا ہے؟

Qwen3.8-27B، NVIDIA کے 4-بٹ فارمیٹ NVFP4 میں، SGLang سے چلایا جاتا ہے، ایک چھوٹے اندازہ لگانے والے مددگار کے ساتھ جسے DFlash2 drafter کہتے ہیں۔ یہ سب ہم نے GB10 کے لیے چنا اور ٹیون کیا۔ ویٹس تقریباً 20 GB لیتے ہیں، اور چلتے وقت مشین کی تقریباً 38 GB میموری خالی رہتی ہے۔

اپنا کوڈ اپنی میز پر رکھیں

اگر آپ سمجھتے ہیں کہ کوڈ کو اسی میز پر رہنا چاہیے جہاں لکھا گیا، تو GitHub پر ریپوزٹری کو اسٹار کریں۔ اسی طرح دوسرے GB10 مالکان کو Mightling ملتا ہے۔

$ curl -fsSL https://github.com/dreamference/mightling/releases/latest/download/install.sh | bash
