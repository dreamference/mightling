SWE‑bench Verified پر تقریباً 69%۔

100 میں سے 68 SWE-bench Verified ٹاسک، ایک DGX Spark پر آف لائن حل ہوئے، تقریباً 47 ٹوکن فی سیکنڈ پر۔ کوڈنگ ایجنٹ، چیٹ اسسٹنٹ اور ڈیسک ٹاپ ایپ، سب کچھ مکمل طور پر آپ کے اپنے GB10 پر چلتا ہے۔ نہ کلاؤڈ۔ نہ اکاؤنٹ۔ نہ API بل۔ نہ ٹیلی میٹری۔ پیمائش کیسے ہوئی

$ curl -fsSL https://github.com/dreamference/mightling/releases/latest/download/install.sh | bash
$ ling-admin server start      # ماڈل ایک بار ڈاؤن لوڈ کرتا ہے (~20 GB)، پھر اسے چلاتا ہے
$ cd ~/your-project && ling    # بس یہی

NVIDIA DGX Spark اور ہر GB10 مشین پر چلتا ہے۔ اسکرپٹ ہر ڈاؤن لوڈ کو ریلیز کے چیک سمز سے جانچتا ہے اور ہر sudo کمانڈ چلانے سے پہلے دکھاتا ہے۔ چاہیں تو پہلے اسے پڑھ لیں۔

Mac اور Linux کلائنٹس

آپ کے باقی کمپیوٹر مقامی نیٹ ورک پر GB10 کا ماڈل استعمال کرتے ہیں۔ Mac یا کسی دوسری Linux مشین پر اوپر والی وہی کمانڈ ling کلائنٹ انسٹال کرتی ہے؛ وہ GB10 کو خود ڈھونڈ لیتا ہے۔

1.7.2 سے یہ Mac پر ڈیسک ٹاپ ایپ کو بھی Applications میں کھولنے کے لیے تیار رکھ دیتی ہے (--no-app اسے چھوڑ دیتا ہے)۔

1.7 میں نیا: Mac، Linux اور Windows پر ڈیسک ٹاپ ایپ

Mightling 1.7.0 کی ڈیسک ٹاپ ایپ Ask اور Work کو ایک ہی ونڈو میں رکھتی ہے۔ Work ایجنٹ سیشنز کے لیے مکمل ورک بینچ ہے: فائلوں، اسکلز اور کمانڈز والا کمپوزر، اسٹیج کرنے، واپس لینے اور کمٹ کرنے کے لیے ریویو پین، ورک ٹریز، ٹرمینل ٹیبز، اور تھریڈ کے ساتھ فائل ٹری اور فائل ٹیبز۔ آپ کے باقی کمپیوٹروں پر یہ آپ کے GB10 کا کلائنٹ ہے، جسے یہ مقامی نیٹ ورک پر ڈھونڈ لیتی ہے۔

macOS پری ویو

1.7.2 سے انسٹال کمانڈ Mightling کو ling کے ساتھ Applications میں رکھ دیتی ہے، اور یہ کسی بھی دوسری ایپ کی طرح کھلتی ہے۔ Apple silicon اور Intel، macOS 12 یا بعد کا۔ ling update اسے اپ ڈیٹ کرتا ہے۔

Linux

GB10 پر mightling_1.7.0_arm64.deb ایپ، اس کی لانچر انٹری اور ling-app کمانڈ انسٹال کرتا ہے، ساتھ وہ سینڈ باکس پروفائل جس کی اسے ضرورت ہے:

$ sudo apt install ./mightling_1.7.0_arm64.deb

پھر اسے ایپلیکیشن مینو سے یا ling app سے کھولیں۔ مزید۔

Windows 11 پری ویو

1.7.2 سے PowerShell والی لائن ایپ بھی انسٹال کرتی ہے، صرف آپ کے لیے اور ایڈمنسٹریٹر کے حقوق کے بغیر، Start مینو انٹری کے ساتھ؛ Settings → Apps سے ہٹ جاتی ہے؛ ling update اسے اپ ڈیٹ کرتا ہے۔ Smart App Control بند ہونا چاہیے۔

انسٹال کرنے کے دوسرے طریقے

ریلیز پیج پر Mac کی dmg (Mightling-<version>-arm64-preview.dmg، یا Intel کے لیے x64) اور Windows انسٹالر (Mightling-Setup-<version>-x64.exe، یا arm64) بھی موجود ہیں۔ یہ بغیر دستخط کے پری ویو ہیں: براؤزر سے ڈاؤن لوڈ کرنے پر پہلی بار انہیں روک دیا جاتا ہے۔ پہلے ہر ایک کو ریلیز کی دستخط شدہ SHA256SUMS سے جانچ لیں۔

  • macOS 15 اور بعد کا: Mightling کو Applications میں گھسیٹیں اور ایک بار کھولیں، پھر System Settings › Privacy & Security › Open Anyway۔ macOS 14 اور اس سے پہلے: ایپ پر Control-کلک کریں › Open۔
  • Windows: SmartScreen › More info › Run anyway۔ Smart App Control بند ہونا چاہیے۔

1.7.0 میں یہ بھی: Night Shift کسی ٹاسک کو کئی بار آزما کر بہترین کوشش رکھ سکتا ہے (/night add --best-of N)، ایک مشین کئی Signal برج چلا سکتی ہے، اور کلائنٹ ایک نیٹ ورک پر دو نوڈز میں سے انتخاب کرتا ہے اور جو نوڈ اسے معلوم ہے اسے کھوتا نہیں۔ ریلیز نوٹس اور ڈاؤن لوڈز۔

SWE-bench Verified، ایک DGX Spark پر ناپا گیا

2026-10-08 کو Mightling 1.5.1 کے ایجنٹ نے Qwen3.8-27B کے ساتھ ایک DGX Spark پر آف لائن SWE-bench Verified کے 100 میں سے 68 ٹاسک حل کیے: 100 ٹاسک کا مقررہ نمونہ، ہر ٹاسک پر ایک کوشش، ڈیفالٹ موڈ۔ تمام 500 ٹاسک پر پھیلائیں تو یہ تخمینہً ≈69% بنتا ہے (95% بینڈ 63.9–73.4%)۔ یہ ہماری اپنی پیمائش ہے، ہماری اپنی مشین پر اور ایک ذیلی سیٹ پر، لیڈر بورڈ کا اندراج نہیں۔

≈69% کا تخمینہ کیسے لگایا گیا

100 ٹاسک Verified کا پانچواں حصہ ہیں، اس لیے پورے سیٹ کا عدد تخمینہ ہے۔ ایک پیرامیٹر والا آئٹم ریسپانس (Rasch) ماڈل Verified کے تمام 175 عوامی جمع کرائے گئے اندراجات کے فی ٹاسک نتائج پر فٹ کیا گیا: ہر ٹاسک کو مشکل اور ہر سسٹم کو صلاحیت ملتی ہے۔ Mightling کی صلاحیت وہ ہے جو ان 100 ٹاسک پر 68 حل ہونے کی وضاحت کرے؛ ≈69% اسی صلاحیت کا تمام 500 پر متوقع اسکور ہے (شائع شدہ اسکورز پر سادہ ریگریشن ایک پوائنٹ کے اندر اتفاق کرتی ہے)۔ جانچنے کے لیے ہر عوامی جمع کرائے گئے اندراج کو صرف انہی 100 ٹاسک پر اسکور کیا گیا اور اس کا مجموعی اسکور اسی طرح پیش گوئی کیا گیا: غلطی 2.4 پوائنٹ (RMSE) رہی، اور اوپر کا بینڈ اس کا ±1.96 گنا ہے۔ جدول کا ہر عدد scripts/swe_bench_compare.py سے SWE-bench/experiments کے عوامی فی ٹاسک ڈیٹا سے دوبارہ بنتا ہے۔

یہ 100 ٹاسک Verified کے ریپوزٹریز میں پورے سیٹ کے تناسب سے پھیلائے گئے ہیں، ان ٹاسک میں سے جن کا ٹیسٹ ماحول arm64 پر چلتا اور تصدیق ہوتا ہے (گولڈ پیچ پاس ہوتا ہے، خالی تبدیلی فیل)۔ شائع شدہ سسٹمز ان 100 پر تمام 500 کے مقابلے میں 1.0 سے 1.5 پوائنٹ کم اسکور کرتے ہیں، اس لیے نمونہ آسان نہیں۔ یہ لیڈر بورڈ کا اندراج نہیں: وہ SWE-bench ٹیم اپنے انفراسٹرکچر پر گریڈ کرتی ہے۔

  1. Mightling: 100 ٹاسک، ہر ایک پر ایک کوشش؛ ایک DGX Spark (GB10، 128 GB)، ماڈل مقامی طور پر چلتا ہے، کلاؤڈ نہیں؛ ڈیفالٹ موڈ 2026-10-08 کو ناپا گیا، refine موڈ 2026-10-09 کو۔ تخمینہ SWE-bench experiments کے فی ٹاسک ڈیٹا سے۔
  2. 500 ٹاسک، ایک کوشش؛ ہارڈویئر مذکور نہیں۔ ماخذ: experiments, 20250805_openhands-Qwen3-Coder-480B-A35B-Instruct۔ وہی ماڈل mini-SWE-agent کے ساتھ: 57/100، 55.4%۔
  3. 500 ٹاسک، ایک کوشش، ایجنٹ ظاہر نہیں؛ ہارڈویئر مذکور نہیں۔ ماخذ: experiments, 20250930_zai_glm4-6۔
  4. 500 ٹاسک، ایک کوشش؛ ہارڈویئر مذکور نہیں۔ ماخذ: experiments, 20260217_mini-v2.0.0_kimi-k2-5-high۔
  5. 500 ٹاسک، ایک کوشش؛ ہارڈویئر مذکور نہیں۔ ماخذ: experiments, 20260217_mini-v2.0.0_deepseek-3-2-high۔
  6. ہر ایک پر 500 ٹاسک؛ ہارڈویئر مذکور نہیں۔ چار جمع کرائے گئے اندراجات: OpenHands (80/100، 77.6%)، live-SWE-agent (80/100، 79.2%)، Sonar Foundation Agent (77/100، 79.2%)، mini-SWE-agent, high (79/100، 76.8%)۔ ایک پہلے کی mini-SWE-agent رن نے 74/100، 74.4% اسکور کیا۔
  7. 500 ٹاسک، ایک کوشش؛ ہارڈویئر مذکور نہیں۔ ماخذ: experiments, 20251120_livesweagent_gemini-3-pro-preview۔ وہی ماڈل mini-SWE-agent کے ساتھ: 72/100، 74.2%۔
  8. لیڈر بورڈ پر شائع شدہ بہترین 20–40B ماڈل۔ 500 ٹاسک؛ ٹیسٹ ٹائم اسکیلنگ میں فی ٹاسک دو یا زیادہ کوششیں ہوتی ہیں؛ ہارڈویئر مذکور نہیں۔ ماخذ: ٹیسٹ ٹائم اسکیلنگ، ایک کوشش۔
  9. 500 ٹاسک، ایک کوشش؛ ہارڈویئر مذکور نہیں۔ ماخذ: experiments, 20251209_mini-v1.17.2_devstral-small-2512۔
  10. GitHub کا اپنا عدد، اپریل 2025: “agent mode achieves a pass rate of 56.0% on SWE-bench Verified with Claude 3.7 Sonnet”۔ ٹاسک، کوششوں کی تعداد اور ہارڈویئر مذکور نہیں؛ لیڈر بورڈ پر نہیں۔ ماخذ: GitHub بلاگ۔
  11. Anthropic اپنے Claude ماڈلز کے لیے SWE-bench Verified شائع کرتی ہے، جو اس کے اپنے سادہ اسکیفولڈ (bash ٹول اور ایڈٹ ٹول) میں چلایا جاتا ہے، Claude Code پروڈکٹ کے لیے نہیں۔ ماخذ: Claude Code، Anthropic کا SWE-bench طریقہ۔
  12. Cursor اپنے بینچ مارک Cursor Bench پر نتائج شائع کرتا ہے، SWE-bench Verified پر نہیں۔ ماخذ: Cursor بلاگ، Composer۔

لیڈر بورڈ کے تمام اعداد: swebench.com اور SWE-bench/experiments ریپوزٹری؛ “وہی 100 ٹاسک” ہر جمع کرائے گئے اندراج کے شائع شدہ فی ٹاسک نتائج ہیں جو صرف ان ٹاسک تک محدود ہیں جو Mightling نے چلائے۔

آپ کا کوڈ آپ کی میز سے باہر نہیں جاتا، اور آپ ثابت بھی کر سکتے ہیں

کلاؤڈ کوڈنگ ایجنٹ آپ کا سورس کوڈ کسی اور کے سرورز پر بھیجتے ہیں۔ Mightling اسے کہیں نہیں بھیجتا: ماڈل آپ کے GB10 پر چلتا ہے، اور Mightling میں کچھ بھی باہر رابطہ نہیں کرتا۔ نہ استعمال کے اعداد و شمار، نہ میٹرکس، نہ سائن اِن، نہ “گمنام” کریش رپورٹس۔ اسی لیے یہ اس کوڈ کے لیے قابل استعمال ہے جو آپ اپ لوڈ نہیں کر سکتے: کلائنٹ کا کام، ریگولیٹڈ ڈیٹا، غیر جاری شدہ پروڈکٹس۔

عمومی سوالات

کیا مجھے GB10 چاہیے؟

ہاں، ماڈل چلانے کے لیے۔ آپ کے باقی کمپیوٹر اسے کلائنٹ کے طور پر استعمال کرتے ہیں: Linux (Arm یا x86) اور macOS اسی انسٹال کمانڈ سے، Windows (Arm یا x86، پری ویو) PowerShell والی لائن سے۔

میں نے Puffin انسٹال کیا تھا۔ کیا یہ وہی ہے؟

جی ہاں: 1.5 میں Puffin کا نام بدل کر Mightling رکھا گیا۔ ایک بار puffin update چلائیں، پھر آخری بار puffin۔ یہ آپ کے سیشنز، سیٹنگز اور لنکس منتقل کر دیتا ہے، اور اس کے بعد کمانڈ ling ہے۔

کیا یہ واقعی مفت ہے؟

جی۔ Mightling AGPL کے تحت اوپن سورس ہے، اور ماڈل کے ویٹس مفت ہیں۔ آپ کا واحد جاری خرچ بجلی ہے۔

مشین کے علاوہ مجھے کیا چاہیے؟

وہ OS جو اس کے ساتھ آتا ہے (DGX OS 7، یا Ubuntu 24.04 جہاں وینڈر دیتا ہے)، NVIDIA Container Toolkit کے ساتھ Docker، Python 3 اور Git۔ سادہ Ubuntu پر ling-admin host check بتاتا ہے کہ کیا کم ہے۔

کیا کبھی کچھ انٹرنیٹ تک پہنچتا ہے؟

صرف وہ جو آپ یا ایجنٹ مانگیں، جیسے آپ کی اپنی مشین پر SearXNG کے ذریعے ویب سرچ، اور پہلی بار کے ڈاؤن لوڈز۔ /airgapped on یہ سب بند کر دیتا ہے۔

یہ کون سا ماڈل چلاتا ہے؟

Qwen3.8-27B، NVIDIA کے 4-بٹ NVFP4 فارمیٹ میں، SGLang سے DFlash2 ڈرافٹر کے ساتھ پیش کیا جاتا ہے، GB10 کے لیے چنا اور ٹیون کیا گیا۔ ویٹس تقریباً 20 GB؛ چلتے وقت مشین کی میموری میں سے تقریباً 38 GB آزاد رہتی ہے۔
