Un agent de programmation, un assistant de chat et une application de bureau, qui tournent entièrement sur votre propre GB10. Pas de cloud. Pas de compte. Pas de facture d'API. Pas de télémétrie. Comment c'est mesuré

$ curl -fsSL https://github.com/dreamference/mightling/releases/latest/download/install.sh | bash
$ ling-admin server start      # télécharge le modèle une seule fois (~20 Go), puis le sert
$ cd ~/your-project && ling    # c'est tout

Fonctionne sur le NVIDIA DGX Spark et sur toute machine GB10. Le script vérifie chaque téléchargement avec les sommes de contrôle de la version et affiche chaque commande sudo avant de l'exécuter. Lisez-le d'abord si vous le souhaitez.

Clients Mac et Linux

Vos autres ordinateurs utilisent le modèle du GB10 via le réseau local. Sur un Mac ou une autre machine Linux, la même commande ci-dessus installe le client ling, qui trouve le GB10 tout seul.

Depuis la 1.7.2, elle place aussi l'application de bureau dans Applications sur un Mac, prête à s'ouvrir (--no-app l'omet).

Client Windows preview

Nouveautés de la 1.7 : l'application de bureau sur Mac, Linux et Windows

L'application de bureau de Mightling 1.7.0 réunit Ask et Work dans une seule fenêtre. Work est un véritable établi pour les sessions d'agent : un compositeur avec fichiers, skills et commandes, un volet de revue pour indexer, annuler et valider, des worktrees, des onglets de terminal, ainsi qu'une arborescence et des onglets de fichiers à côté de la conversation. Sur vos autres ordinateurs, c'est un client de votre GB10, qu'elle trouve sur le réseau local.

macOS preview

Depuis la 1.7.2, la commande d'installation place Mightling dans Applications à côté de ling, et elle s'ouvre comme n'importe quelle autre application. Apple silicon et Intel, macOS 12 ou plus récent. ling update la met à jour.

Linux

Sur le GB10, mightling_1.7.0_arm64.deb installe l'application, son entrée de lanceur et la commande ling-app, avec le profil de bac à sable dont elle a besoin :

$ sudo apt install ./mightling_1.7.0_arm64.deb

Ouvrez-la ensuite depuis le menu des applications, ou avec ling app. En savoir plus.

Windows 11 preview

Depuis la 1.7.2, la ligne PowerShell installe aussi l'application, pour vous seul et sans droits d'administrateur, avec une entrée dans le menu Démarrer ; Paramètres → Applications la supprime ; ling update la met à jour. Smart App Control doit être désactivé.

Autres façons d'installer

La page de la version propose aussi le dmg pour Mac (Mightling-<version>-arm64-preview.dmg, ou x64 pour Intel) et l'installeur Windows (Mightling-Setup-<version>-x64.exe, ou arm64). Ce sont des previews non signées : téléchargées dans un navigateur, elles sont bloquées la première fois. Vérifiez d'abord chacune avec le fichier SHA256SUMS signé de la version.

  • macOS 15 et plus récent : faites glisser Mightling dans Applications et ouvrez-la une fois, puis Réglages Système › Confidentialité et sécurité › Ouvrir quand même. Sous macOS 14 et antérieur, Control-clic sur l'application › Ouvrir.
  • Windows : SmartScreen › Informations complémentaires › Exécuter quand même. Smart App Control doit être désactivé.

Également dans la 1.7.0 : Night Shift peut tenter une tâche plusieurs fois et garder la meilleure tentative (/night add --best-of N), une machine peut faire tourner plusieurs passerelles Signal, et un client choisit entre deux nœuds d'un même réseau sans perdre celui qu'il connaît. À lire comme une mise en perspective, pas comme un classement. Sur les mêmes 100 tâches, Mightling en a résolu autant que Qwen3-Coder-480B et GLM-4.6, des modèles bien plus gros, mais chaque ligne utilise un agent différent, un matériel différent et, pour les lignes du classement, les images de test x86 officielles, alors que les nôtres ont tourné sur des images arm64 de la communauté. En mode refine, une première session étudie la tâche sans rien modifier, puis une session neuve l'exécute : il a résolu une tâche de plus que le mode par défaut (69 contre 68, chaque mode gagnant des tâches que l'autre perdait), pour environ 2,2 fois plus de temps par tâche ; il reste donc optionnel (ling --refine).

Comment le ≈69 % est estimé

100 tâches font un cinquième de Verified, donc le chiffre sur l'ensemble complet est une estimation. Un modèle de réponse à l'item à un paramètre (Rasch) est ajusté sur les résultats par tâche des 175 soumissions publiques de Verified : chaque tâche reçoit une difficulté et chaque système une aptitude. L'aptitude de Mightling est celle qui explique 68 tâches résolues sur ces 100 ; ≈69 % est le score attendu de cette aptitude sur les 500 (une simple régression sur les scores publiés concorde à un point près). Pour vérifier, chaque soumission publique a été notée sur ces 100 tâches seulement et son score global prédit de la même façon : l'erreur était de 2,4 points (RMSE), et l'intervalle ci-dessus vaut ±1,96 fois cette valeur. Chaque nombre du tableau est reproduit par scripts/swe_bench_compare.py à partir des données publiques par tâche de SWE-bench/experiments.

Les 100 tâches sont réparties entre les dépôts de Verified proportionnellement à l'ensemble complet, parmi les tâches dont l'environnement de test s'exécute et se valide sur arm64 (le patch de référence passe, une modification vide échoue). Les systèmes publiés obtiennent 1,0 à 1,5 point de moins sur ces 100 que sur les 500 : l'échantillon n'est donc pas facile. Ce n'est pas une entrée du classement : celles-ci sont évaluées par l'équipe SWE-bench sur sa propre infrastructure.

Votre code ne quitte pas votre bureau — et vous pouvez le prouver

Les agents de programmation dans le cloud envoient votre code source sur les serveurs d'un tiers. Mightling ne l'envoie nulle part : le modèle tourne sur votre GB10, et rien dans Mightling ne contacte l'extérieur. Pas de statistiques d'usage, pas de métriques, pas de connexion, pas de rapports de plantage « anonymes ». Il devient ainsi utilisable pour du code que vous n'avez pas le droit d'envoyer : travail pour des clients, données réglementées, produits non sortis.

Une commande lance une vraie session Mightling sous strace et liste chaque connexion réseau qu'elle a établie :

$ ling-admin audit egress
✔ Egress audit: pass
Network destinations:
   127.0.0.1:8000     29x  model server
   127.0.0.1:8767      1x  Gmail search service
DNS queries: none
Networked git commands: none

Tout est resté sur 127.0.0.1. Pas une seule requête DNS.

Besoin d'une garantie ferme ?

Tapez /airgapped on et chaque commande que l'agent exécute reçoit du noyau Linux un espace de noms réseau vide. Ce n'est pas une demande polie faite au modèle : il n'y a tout simplement aucun réseau à atteindre. Full Access, qui contournerait le bac à sable, est refusé en même temps.

Ce qui peut sortir, et quand

Seulement ce que vous ou l'agent demandez : une recherche web (via un SearXNG privé sur votre propre machine), le téléchargement d'une page, une requête en lecture seule vers un compte Google que vous avez connecté, ou une vérification de mise à jour. Avec /airgapped on, rien de tout cela.

FAQ

Ai-je besoin d'un GB10 ?

Oui, pour faire tourner le modèle. Vos autres ordinateurs l'utilisent comme clients : Linux (Arm ou x86) et macOS avec la même commande d'installation, Windows (Arm ou x86, preview) avec la ligne PowerShell.

J'ai installé Puffin. C'est la même chose ?

Oui : Puffin a été rebaptisé Mightling dans la 1.5. Lancez puffin update une fois, puis puffin une dernière fois. Il déplace vos sessions, réglages et liens, et la commande devient ensuite ling.

Est-ce vraiment gratuit ?

Oui. Mightling est open source sous licence AGPL, et les poids du modèle sont libres. Votre seul coût de fonctionnement est l'électricité.

De quoi ai-je besoin en plus de la machine ?

Du système livré avec elle (DGX OS 7, ou Ubuntu 24.04 là où le constructeur le propose), de Docker avec le NVIDIA Container Toolkit, de Python 3 et de Git. Sur un Ubuntu ordinaire, ling-admin host check vous dit ce qui manque.

Quelque chose atteint-il jamais internet ?

Seulement ce que vous ou l'agent demandez, comme une recherche web via SearXNG sur votre propre machine, et les téléchargements du premier lancement. /airgapped on coupe tout cela.

Quel modèle fait-il tourner ?

Qwen3.8-27B au format NVFP4 4 bits de NVIDIA, servi par SGLang avec un drafter DFlash2, choisi et réglé pour le GB10. Environ 20 Go de poids ; il reste environ 38 Go de mémoire libres sur la machine pendant le service.

Gardez votre code sur votre bureau

Si vous pensez que le code doit rester sur le bureau où il a été écrit, mettez une étoile au dépôt : c'est ainsi que les autres propriétaires de GB10 découvrent Mightling.
