1.7 新功能：适用于 Mac、Linux 和 Windows 的桌面应用

Mightling 1.7.0 的桌面应用把 Ask 和 Work 放在同一个窗口里。Work 是一个完整的智能体会话工作台：带文件、技能和命令的输入框，可暂存、还原和提交的审阅面板，工作树，终端标签页，以及对话旁边的文件树和文件标签页。在你的其他电脑上，它是 GB10 的客户端，会在本地网络中自动找到 GB10。

macOS 预览

从 1.7.2 起，安装命令会把 Mightling 与 ling 一起装进“应用程序”,像其他应用一样直接打开。支持 Apple 芯片和 Intel,macOS 12 或更高版本。ling update 会更新它。

Linux

在 GB10 上，mightling_1.7.0_arm64.deb 会安装该应用、它的启动器条目和 ling-app 命令，以及所需的沙箱配置文件：

$ sudo apt install ./mightling_1.7.0_arm64.deb

然后从应用程序菜单打开，或使用 ling app。详情。

Windows 11 预览

从 1.7.2 起，PowerShell 那一行命令同样会安装该应用，仅为当前用户安装，无需管理员权限，并带开始菜单项；在“设置 → 应用”中即可卸载；ling update 会更新它。必须关闭智能应用控制（Smart App Control）。

其他安装方式

发布页还提供 Mac 的 dmg（Mightling-<version>-arm64-preview.dmg,Intel 用 x64）和 Windows 安装程序（Mightling-Setup-<version>-x64.exe,或 arm64）。它们是未签名的预览版：用浏览器下载后，首次打开会被拦截。请先对照发布版已签名的 SHA256SUMS 逐一校验。

  • macOS 15 及更高版本：把 Mightling 拖到“应用程序”并打开一次，然后进入 系统设置 › 隐私与安全性 › 仍要打开。在 macOS 14 及更早版本上，按住 Control 点按该应用 › 打开。
  • Windows:SmartScreen › 更多信息 › 仍要运行。必须关闭智能应用控制（Smart App Control）。

1.7.0 还带来：Night Shift 可以把一项任务尝试多次并保留最佳结果（/night add --best-of N），一台机器可运行多个 Signal 桥接，同一网络中有两个节点时，客户端可在二者之间选择，且不会丢掉已知的那个。发布说明与下载。

SWE-bench Verified，在一台 DGX Spark 上实测

2026-10-08，Mightling 1.5.1 的智能体搭配 Qwen3.8-27B，在一台 DGX Spark 上离线解决了 100 道中的 68 道 SWE-bench Verified 任务：固定抽取 100 道任务，每道只尝试一次，默认模式。按全部 500 道任务折算，估计为 ≈69%（95% 区间 63.9–73.4%）。这是我们在自己的机器上、基于子集的自测结果，不是排行榜成绩。

请把它当作参照，而不是排名。在同样的 100 道任务上，Mightling 解决的数量与 Qwen3-Coder-480B 和 GLM-4.6 相当，而后两者的规模是它的许多倍；但每一行用的智能体不同、硬件不同，排行榜上的各行还使用官方的 x86 测试镜像，而我们用的是社区的 arm64 镜像。在 refine 模式下，第一个会话只研究任务、不改动任何东西，再由一个全新的会话动手：它比默认模式多解决了一道任务（69 对 68，双方各自赢下了对方没解出的任务），每道任务耗时约为 2.2 倍，所以它仍是可选项（ling --refine)。

≈69% 是如何估算的

100 道任务只占 Verified 的五分之一，所以全集数字是估计值。我们用单参数项目反应（Rasch）模型，拟合全部 175 份公开 Verified 提交的逐任务结果：每道任务有一个难度，每个系统有一个能力值。Mightling 的能力值，就是能解释这 100 道任务中解决 68 道的那一个；≈69% 是该能力值在全部 500 道任务上的期望得分（对已公布分数做普通回归，结果相差在一个百分点以内）。为了检验，我们只用这 100 道任务给每份公开提交打分，并用同样方式预测其总分：误差为 2.4 个百分点（RMSE），上面的区间就是它的 ±1.96 倍。表中的每个数字都可以用 scripts/swe_bench_compare.py 根据 SWE-bench/experiments 的公开逐任务数据复现。

这 100 道任务按比例分布在 Verified 的各个代码仓库中，并且只取测试环境能在 arm64 上运行并通过验证的任务（标准补丁通过，空改动失败）。已发布的系统在这 100 道上的得分比在全部 500 道上低 1.0 到 1.5 个百分点，所以这个样本并不容易。它不是排行榜条目：排行榜成绩由 SWE-bench 团队在他们自己的基础设施上评测。

你的代码不会离开你的桌面，而且你可以自己验证

云端编程智能体会把你的源代码发送到别人的服务器。Mightling 哪儿也不发：模型运行在你的 GB10 上，Mightling 里没有任何东西会回传数据。没有使用统计，没有指标，没有登录，也没有“匿名”崩溃报告。因此它可以用于你无权上传的代码：客户项目、受监管的数据、未发布的产品。

一条命令就能在 strace 下运行一次真实的 Mightling 会话，并列出它建立的每一个网络连接：

$ ling-admin audit egress
✔ Egress audit: pass
Network destinations:
   127.0.0.1:8000     29x  model server
   127.0.0.1:8767      1x  Gmail search service
DNS queries: none
Networked git commands: none

一切都留在 127.0.0.1。没有一次 DNS 查询。

需要硬性保证？

输入 /airgapped on,智能体运行的每条命令都会由 Linux 内核分配一个空的网络命名空间。这不是对模型的客气请求：根本就没有网络可连。同时，会绕过沙箱的 Full Access 也会被拒绝。

哪些会外发，何时外发

只有你或智能体要求的：网页搜索（经由你自己机器上的私有 SearXNG）、抓取网页、对你已连接的 Google 账号的只读请求，或检查更新。在 /airgapped on 下，这些全都不会发生。

常见问题

我必须有 GB10 吗？

运行模型需要。你的其他电脑则作为客户端使用它：Linux（Arm 或 x86）和 macOS 用同一条安装命令，Windows（Arm 或 x86，预览版）用那一行 PowerShell 命令。

我装过 Puffin，这就是它吗？

是的：Puffin 在 1.5 中更名为 Mightling。先运行一次 puffin update,再最后运行一次 puffin。它会迁移你的会话、设置和链接，此后命令就是 ling。

真的免费吗？

是的。Mightling 以 AGPL 开源，模型权重也是免费的。你唯一的运行成本是电费。

除了这台机器，我还需要什么？

它自带的操作系统（DGX OS 7，或厂商提供时的 Ubuntu 24.04）、装有 NVIDIA Container Toolkit 的 Docker、Python 3 和 Git。在普通 Ubuntu 上，ling-admin host check 会告诉你缺什么。

会有东西连到互联网吗？

只有你或智能体要求的内容，例如经由你自己机器上的 SearXNG 进行的网页搜索，以及首次下载。/airgapped on 会把这一切全部关闭。

它运行哪个模型？

NVIDIA 4 位 NVFP4 格式的 Qwen3.8-27B，由 SGLang 搭配 DFlash2 草稿模型提供服务，专为 GB10 选定并调优。权重约 20 GB；服务期间机器内存仍有约 38 GB 空闲。

如果你也认为代码应该留在写下它的那张桌子上，请给仓库点个星：其他 GB10 用户就是这样发现 Mightling 的。
