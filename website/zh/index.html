安装

$ curl -fsSL https://github.com/dreamference/mightling/releases/latest/download/install.sh | bash
$ ling-admin server start      # 下载一次模型（约 20 GB），然后启动它
$ cd ~/your-project && ling    # 就这些

它可以在 NVIDIA DGX Spark 和其他所有 GB10 机器上使用。脚本会对照发布版的校验和检查每个下载文件，并且在运行每条 sudo 命令之前先给你看。你可以先读一遍脚本。

Mac 和 Linux 客户端

你的其他电脑通过家里或办公室的网络借用 GB10 上的模型。在 Mac 或另一台 Linux 机器上，同一条命令会安装 ling，也就是你输入命令的那一部分。它会自己找到 GB10。

从 1.7.2 起，它还会在 Mac 的“应用程序”里装好桌面应用，随时可以打开。如果不想要，加上 --no-app。

Windows 客户端 预览

> irm https://github.com/dreamference/mightling/releases/latest/download/install.ps1 | iex

在 PowerShell 里输入这条命令。它不需要管理员权限（从 1.7.2 起，桌面应用也是如此）。之后 Windows 会问你一次，是否建立一个隔离的空间，让智能体在里面运行命令。安装程序还没有签名，所以必须关闭智能应用控制（Smart App Control）。读一读脚本。

其他安装方式

发布页上还有 Mac 的磁盘映像（Mightling-<version>-arm64-preview.dmg，Intel 用 x64）和 Windows 安装程序（Mightling-Setup-<version>-x64.exe，或 arm64）。它们是未签名的预览版，所以用浏览器下载后，系统第一次会拦下它们。打开之前，请先对照发布版里已签名的 SHA256SUMS 文件检查一下。

  • macOS 15 及更新版本：把 Mightling 拖进“应用程序”，打开一次。然后进入“系统设置 › 隐私与安全性”，点击仍要打开。macOS 14 及更早版本，按住 Control 点击这个应用，选择“打开”。
  • Windows:SmartScreen › 更多信息 › 仍要运行。必须关闭智能应用控制（Smart App Control）。

先试试这些

或者用 /night add <task> 把活留到今晚。你睡觉的时候，Mightling 会把清单过一遍，每个任务在自己的 git 分支上完成，早上你再检查这些分支。

$ ling "explain this repository to me like I'm new on the team"
# reads the code index (ling-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ling "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ling-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

🧭 代码索引

整个项目里各个东西在哪里定义、谁在使用它们，都有一份清单，所以智能体可以直接查代码，而不是靠猜去搜。

🔎 网页搜索和网页获取

搜索通过你自己机器上的私有 SearXNG 进行，所以不需要搜索账号，也不用去申请密钥。问题本身仍然会发到网上去找答案。

🌙 Night Shift

睡前输入 /night add <task>。到早上，每个任务都在自己的 git 分支上做好了。除非你自己动手，否则什么都不会合并或推送。

你能得到什么

1.7.0 的桌面应用把使用 Mightling 的两种方式放进了一个窗口：Ask 用来提问，Work 用来让智能体修改你的代码。Work 有一个输入任务的框（可以附上文件、技能和命令），一个在你保留或撤销修改之前先检查改动的面板，相互独立的代码副本（工作树），终端标签页，以及对话旁边的文件树。在你的其他电脑上，这个应用会和你的 GB10 通信，并在网络里自动找到它。

ling · ling-code · ling-docs

🖥️ ling，在你终端里的智能体

它会阅读你的项目，运行命令和测试，编辑代码，并且在做任何有风险的事之前先问你。

你的代码留在你的桌上，而且你可以自己验证

云端编程智能体会把你的源代码发送到别人的电脑上。Mightling 哪儿也不发。模型运行在你的 GB10 上，Mightling 里没有任何东西会回传数据：没有使用统计，没有测量，没有登录，连“匿名”崩溃报告也没有。所以你可以把它用在不允许上传的代码上，比如客户的项目、受保护的数据或尚未发布的产品。

一条命令就能在 strace 下运行一次真实的 Mightling 会话（strace 是一个观察程序每一次调用的工具），然后列出这次会话打开的每个网络连接：

$ ling-admin audit egress
✔ Egress audit: pass
Network destinations:
   127.0.0.1:8000     29x  model server
   127.0.0.1:8767      1x  Gmail search service
DNS queries: none
Networked git commands: none

全部都留在 127.0.0.1，也就是机器自己和自己说话。没有一次 DNS 查询（DNS 查询就是向互联网询问某个名字的地址）。

想要确切的保证？

输入 /airgapped on。之后智能体运行的每条命令，都会从 Linux 内核得到一个空的网络。这不是对模型的客气请求，而是根本没有网络可连。同时，能绕过沙盒的完全访问（Full Access）会被拒绝。

哪些会外发，何时外发

只有你或智能体要求的东西：网页搜索（通过运行在你自己机器上的私有 SearXNG，不过搜索本身还是会发到网上）、获取网页、对你连接的 Google 账号的只读请求，或检查更新。使用 /airgapped on 后，这些都不会发生。

为什么选 Mightling

🔒 私密

模型、你的代码、你的问题和它的回答，都留在原来的机器上。

  • 无账号，无跟踪
  • 可以再次运行的出站流量审计
  • /airgapped on,由内核强制执行

⚡ 很快，而且不用付账单

处理代码~48 tok/s
写代码69 tok/s
JSON84 tok/s
文本32 tok/s
读代码~1,800 tok/s
对话的记忆262K

这些是在 GB10 上一次做一个任务的速度。模型用了一个叫推测解码的办法：一个小助手往前猜好几个词，大模型一次就把这些猜测都检查完。“处理代码”是在真实的智能体会话中测得的。写代码、JSON 和文字，则分别按那种输出测得。最后一行是它一次能记住多少文字：262K 个 token，大约几百页。想的话，可以同时运行四个智能体。没有配额，也没有“请稍候”。

✨ 几乎不用设置

  • 不用调：模型、内存大小、底层代码和推测解码，我们都是为 GB10 选好的。
  • 不应该让你的机器卡死：加载模型之前它会先检查机器，加载过程中会盯着内存。
  • 你的其他电脑能找到它，就在你的网络里。
  • 更新只要一条命令：ling update。

SWE-bench Verified，在一台 DGX Spark 上实测

SWE-bench Verified 是从开源程序里取来的 500 道真实题目。每一道题，智能体都要修改代码，让测试通过。2026-10-08，我们让 Mightling 1.5.1 搭配 Qwen3.8-27B 模型，在一台不联网的 DGX Spark 上做了其中 100 道。每道题只试一次，用默认模式，它解出了 100 道中的 68 道。如果按比例推算到全部 500 道，我们估计约为 69%，上下相差几个百分点（95% 区间是 63.9 到 73.4%）。这是我们自己在自己的机器上、用一部分题目测出来的，不是官方排行榜上的成绩。

我们是怎么估出 69% 的

100 道题只占 Verified 的五分之一，所以全部 500 道的数字是估计值。做法是这样的：取全部 175 份公开的 Verified 提交，一道题一道题地看结果。用单参数的项目反应（Rasch）模型，给每道题定一个难度，给每个系统定一个能力值。Mightling 的能力值，就是在这 100 道题上能解出 68 道的那个值，而大约 69% 就是这个能力值在全部 500 道题上的得分。对已公布分数做普通回归，结果相差不到一个百分点。我们还用别人检验了这个方法：对每一份公开提交，只用它在这 100 道题上的得分，去预测它在全部 500 道题上的得分。误差是 2.4 个百分点（RMSE），上面的区间是它的 1.96 倍，两边各取一份。表里的每个数字都可以用 scripts/swe_bench_compare.py 重现，数据来自 SWE-bench/experiments 里公开的逐题数据。

我们按 Verified 里各个程序所占的比例，把这 100 道题分摊到各个程序上。题目是从测试环境能在 arm64 上正常运行并通过检查的题里抽出来的（正确的修复能通过，什么都不做则失败）。已公布的系统在这 100 道题上的得分比在全部 500 道上低 1.0 到 1.5 分，所以这个样本并不容易。但它仍然不是排行榜成绩，因为排行榜是由 SWE-bench 团队在他们自己的机器上评分的。

常见问题

我必须有 GB10 吗？

是的，用来运行模型。你的其他电脑是借用它的客户端：Linux（Arm 或 x86）和 macOS 用同一条安装命令，Windows（Arm 或 x86，预览版）用那行 PowerShell 命令。

我装过 Puffin。这是同一个程序吗？

是的。Puffin 在 1.5 版改名为 Mightling。运行一次 puffin update，然后最后再运行一次 puffin。它会把你的会话、设置和链接迁移过来，之后命令就是 ling。

真的一分钱都不用花吗？

程序和模型都不要钱。Mightling 以 AGPL 开源，模型权重也可以免费使用。你只需要为机器和它用的电付钱。

除了这台机器，我还需要什么？

它自带的操作系统（DGX OS 7，或 NVIDIA 提供支持的 Ubuntu 24.04）、装有 NVIDIA Container Toolkit 的 Docker、Python 3 和 Git。在普通 Ubuntu 上，ling-admin host check 会告诉你缺什么。

会有东西发到互联网上吗？

只有你或智能体要求的东西，比如网页搜索（通过运行在你自己机器上的 SearXNG）和第一次使用时的下载。用了 /airgapped on，这些都会关掉。

它运行哪个模型？

Qwen3.8-27B，采用 NVIDIA 的 4 位格式 NVFP4，由 SGLang 提供服务，并配有一个叫 DFlash2 drafter 的小型猜词助手。这一切都是我们为 GB10 挑选并调好的。权重大约占 20 GB，运行时机器内存还剩大约 38 GB 空闲。

让你的代码留在你的桌面上

如果你也认为代码应该留在写出它的那张桌子上，请在 GitHub 上给这个仓库点个星。其他 GB10 用户就是这样找到 Mightling 的。
