इंस्टॉल

$ curl -fsSL https://github.com/dreamference/mightling/releases/latest/download/install.sh | bash
$ ling-admin server start      # मॉडल एक बार डाउनलोड होता है (~20 GB), फिर चालू हो जाता है
$ cd ~/your-project && ling    # बस, इतना ही

NVIDIA DGX Spark और हर GB10 मशीन पर चलता है। स्क्रिप्ट हर डाउनलोड को रिलीज़ के चेकसम से जाँचती है और हर sudo कमांड चलाने से पहले उसे दिखा देती है। चाहें तो पहले उसे पढ़ लें।

Mac और Linux क्लाइंट

आपके बाकी कंप्यूटर लोकल नेटवर्क पर GB10 के मॉडल का इस्तेमाल करते हैं। Mac या किसी दूसरी Linux मशीन पर ऊपर वाली वही कमांड ling क्लाइंट इंस्टॉल करती है; वह GB10 को खुद ढूँढ लेता है।

1.7.2 से यह Mac पर डेस्कटॉप ऐप को भी Applications में रख देता है, खोलने के लिए तैयार (--no-app से इसे छोड़ा जा सकता है)।

Windows क्लाइंट प्रीव्यू

> irm https://github.com/dreamference/mightling/releases/latest/download/install.ps1 | iex

PowerShell में। यह एडमिनिस्ट्रेटर अधिकार के बिना इंस्टॉल होता है (1.7.2 से डेस्कटॉप ऐप भी), फिर Windows एक बार एजेंट का सैंडबॉक्स सेट करने को कहता है। अभी साइन नहीं किया गया है, इसलिए Smart App Control बंद होना चाहिए। स्क्रिप्ट पढ़ें।

इंस्टॉल करने के दूसरे तरीके

रिलीज़ पेज पर Mac का dmg (Mightling-<version>-arm64-preview.dmg, Intel के लिए x64) और Windows इंस्टॉलर (Mightling-Setup-<version>-x64.exe, या arm64) भी हैं। ये बिना साइन किए प्रीव्यू हैं: ब्राउज़र से डाउनलोड करने पर पहली बार रोक दिए जाते हैं। पहले हर एक को रिलीज़ की साइन की हुई SHA256SUMS से जाँच लें।

  • macOS 15 और बाद के संस्करण: Mightling को Applications में खींचें और एक बार खोलें, फिर System Settings › Privacy & Security › Open Anyway। macOS 14 और पुराने में ऐप पर Control-क्लिक करें › Open।
  • Windows: SmartScreen › More info › Run anyway। Smart App Control बंद होना चाहिए।

पहले ये आज़माएँ

या आज रात के लिए काम कतार में लगाएँ: /night add <task>। आपके सोते समय Mightling कतार निपटाता है, हर टास्क अपनी git ब्रांच पर, और सुबह चाय पर आप ब्रांच देख लेते हैं।

$ ling "explain this repository to me like I'm new on the team"
# reads the code index (ling-code outline, def, refs, callers) instead of grepping,
# then walks you through the layout, the entry points and how they connect
$ ling "the tests are failing: find out why and fix them"
# runs the tests, reads the failure, edits the code and runs the tests again,
# asking before anything risky
> /night add --best-of 3 add input validation to the signup form, with tests
# tonight: three attempts, each in its own git worktree; the one the chooser picks
# is committed on its own branch, and nothing is merged or pushed
$ ling-admin night status      # the timer, the window and the queue
> /night apply <id>            # in the morning: bring the branch back as uncommitted changes

🪟 डेस्कटॉप ऐप प्रीव्यू

Ask और Work एक विंडो में, GB10, Mac, Linux या Windows पर: अनुमोदन वाले एजेंट सेशन, रिव्यू पेन, वर्कट्री और अनडू। 1.7 में नया।

वेब सर्च, इमेज सर्च और डिक्टेशन के साथ सवाल, और आपके एजेंट सेशन, इसी मशीन से या जोड़े गए फ़ोन से, उसी लोकल मॉडल पर।

डॉक्स →

macOS प्रीव्यू

1.7.2 से इंस्टॉल कमांड Mightling को ling के साथ Applications में रख देती है, और यह किसी भी दूसरे ऐप की तरह खुलता है। Apple silicon और Intel, macOS 12 या उसके बाद। ling update इसे अपडेट करता है।

Linux

GB10 पर mightling_1.7.0_arm64.deb ऐप, उसकी लॉन्चर एंट्री और ling-app कमांड इंस्टॉल करता है, साथ में उसके लिए ज़रूरी सैंडबॉक्स प्रोफ़ाइल:

$ sudo apt install ./mightling_1.7.0_arm64.deb

फिर इसे एप्लिकेशन मेन्यू से खोलें, या ling app से। और जानें।

Windows 11 प्रीव्यू

1.7.2 से PowerShell की लाइन ऐप को भी इंस्टॉल कर देती है, सिर्फ़ आपके लिए और एडमिनिस्ट्रेटर अधिकार के बिना, Start मेन्यू एंट्री के साथ; Settings → Apps से इसे हटाया जा सकता है; ling update इसे अपडेट करता है। Smart App Control बंद होना चाहिए।

ling-admin mcp · ling signal · ling chat

JetBrains, VS Code और आपका फ़ोन

stdio MCP (ling-admin mcp) के ज़रिए JetBrains या VS Code जोड़ें, या Signal (Note to Self), Telegram (Mini App रिपॉज़िटरी वर्कबेंच सहित) और Tailscale पर Matrix से अपने GB10 को संदेश भेजें। हर फ़ोन ब्रिज तब तक बंद रहता है जब तक आप उसे चालू नहीं करते।

📬 Gmail, Drive, Calendar प्रीव्यू

रीड-ओनली, ऐसे साइन-इन से जो आपकी मशीन पर ही रहता है। /airgapped on पर पूरी तरह बंद।

आपका कोड आपकी डेस्क से बाहर नहीं जाता, और आप इसे साबित कर सकते हैं

क्लाउड कोडिंग एजेंट आपका सोर्स कोड किसी और के सर्वर पर भेजते हैं। Mightling उसे कहीं नहीं भेजता: मॉडल आपके GB10 पर चलता है, और Mightling में कुछ भी बाहर किसी सर्वर से संपर्क नहीं करता। कोई उपयोग विश्लेषण नहीं, कोई मेट्रिक्स नहीं, कोई साइन-इन नहीं, कोई "अनाम" क्रैश रिपोर्ट नहीं। इसलिए इसे उस कोड पर इस्तेमाल किया जा सकता है जिसे अपलोड करने की अनुमति नहीं: क्लाइंट का काम, नियंत्रित डेटा, अप्रकाशित उत्पाद।

एक कमांड strace के अंतर्गत असली Mightling सेशन चलाती है और उसके बनाए हर नेटवर्क कनेक्शन की सूची देती है:

$ ling-admin audit egress
✔ Egress audit: pass
Network destinations:
   127.0.0.1:8000     29x  model server
   127.0.0.1:8767      1x  Gmail search service
DNS queries: none
Networked git commands: none

सब कुछ 127.0.0.1 पर रहा। एक भी DNS लुकअप नहीं।

पक्की गारंटी चाहिए?

/airgapped on लिखें और एजेंट की चलाई हर कमांड को Linux कर्नेल से खाली नेटवर्क नेमस्पेस मिलता है। यह मॉडल से विनम्र अनुरोध नहीं है: पहुँचने के लिए नेटवर्क है ही नहीं। Full Access, जो सैंडबॉक्स को बायपास करता, उसी समय अस्वीकार कर दिया जाता है।

क्या बाहर जा सकता है, और कब

सिर्फ़ वही जो आप या एजेंट माँगें: वेब सर्च (आपकी अपनी मशीन पर निजी SearXNG के ज़रिए), पेज फ़ेच, आपके जोड़े हुए Google अकाउंट को रीड-ओनली अनुरोध, या अपडेट की जाँच। /airgapped on पर इनमें से कुछ नहीं।

✨ कुछ कॉन्फ़िगर नहीं करना

  • कोई ट्यूनिंग नहीं: मॉडल, कॉन्टेक्स्ट, कर्नेल और स्पेकुलेटिव डिकोडिंग GB10 के लिए चुने गए हैं।
  • यह आपकी मशीन को फ़्रीज़ नहीं करेगा: होस्ट की जाँच होती है और लोड के दौरान मेमोरी प्रेशर पर नज़र रखी जाती है।
  • आपकी दूसरी मशीनें इसे ढूँढ लेती हैं, लोकल नेटवर्क पर।
  • अपडेट एक कमांड में: ling update।

SWE-bench Verified, एक DGX Spark पर मापा गया

2026-10-08 को Mightling 1.5.1 के एजेंट ने Qwen3.8-27B के साथ एक DGX Spark पर, ऑफ़लाइन, SWE-bench Verified के 100 में से 68 टास्क हल किए: 100 टास्क का एक तय नमूना, हर टास्क पर एक प्रयास, डिफ़ॉल्ट मोड। सभी 500 टास्क पर स्केल करने पर यह अनुमानित ≈69% है (95% दायरा 63.9–73.4%)। यह हमारी अपनी मशीन पर, एक उपसमूह पर, हमारा अपना माप है, लीडरबोर्ड की एंट्री नहीं।

≈69% का अनुमान कैसे लगाया गया

100 टास्क Verified का पाँचवाँ हिस्सा हैं, इसलिए पूरे सेट का आँकड़ा एक अनुमान है। सभी 175 सार्वजनिक Verified सबमिशन के प्रति-टास्क नतीजों पर एक एक-पैरामीटर आइटम-रिस्पॉन्स (Rasch) मॉडल फ़िट किया गया है: हर टास्क की एक कठिनाई और हर सिस्टम की एक क्षमता। Mightling की क्षमता वह है जो इन 100 टास्क पर 68 हल होने को समझाती है; ≈69% उस क्षमता का सभी 500 पर अपेक्षित स्कोर है (प्रकाशित स्कोर पर साधारण रिग्रेशन एक अंक के भीतर सहमत है)। जाँचने के लिए हर सार्वजनिक सबमिशन को सिर्फ़ इन्हीं 100 टास्क पर स्कोर किया गया और उसके कुल स्कोर का इसी तरह अनुमान लगाया गया: त्रुटि 2.4 अंक (RMSE) रही, और ऊपर का दायरा उसका ±1.96 गुना है। तालिका का हर आँकड़ा scripts/swe_bench_compare.py से SWE-bench/experiments के सार्वजनिक प्रति-टास्क डेटा से दोहराया जा सकता है।

ये 100 टास्क Verified की रिपॉज़िटरी में पूरे सेट के अनुपात में फैले हैं, उन टास्क में से जिनका टेस्ट एनवायरनमेंट arm64 पर चलता और सत्यापित होता है (गोल्ड पैच पास होता है, खाली बदलाव फ़ेल)। प्रकाशित सिस्टम इन 100 पर सभी 500 की तुलना में 1.0 से 1.5 अंक कम स्कोर करते हैं, इसलिए यह नमूना आसान नहीं है। यह लीडरबोर्ड की एंट्री नहीं है: उनकी ग्रेडिंग SWE-bench टीम अपने इन्फ्रास्ट्रक्चर पर करती है।

FAQ

क्या मुझे GB10 चाहिए?

हाँ, मॉडल चलाने के लिए। आपके बाकी कंप्यूटर इसके क्लाइंट की तरह चलते हैं: Linux (Arm या x86) और macOS उसी इंस्टॉल कमांड से, Windows (Arm या x86, प्रीव्यू) PowerShell की लाइन से।

मैंने Puffin इंस्टॉल किया था। क्या यह वही है?

हाँ: 1.5 में Puffin का नाम बदलकर Mightling हो गया। एक बार puffin update चलाएँ, फिर आखिरी बार puffin। यह आपके सेशन, सेटिंग और लिंक नए नाम पर ले आता है, और उसके बाद कमांड ling है।

क्या यह सच में मुफ़्त है?

हाँ। Mightling AGPL के तहत ओपन सोर्स है, और मॉडल के वेट्स मुफ़्त हैं। आपका एकमात्र चालू खर्च बिजली है।

मशीन के अलावा मुझे क्या चाहिए?

उसके साथ आने वाला OS (DGX OS 7, या Ubuntu 24.04 जहाँ विक्रेता देता है), NVIDIA Container Toolkit के साथ Docker, Python 3 और Git। सादे Ubuntu पर ling-admin host check बता देता है कि क्या कम है।

क्या कुछ कभी इंटरनेट तक पहुँचता है?

सिर्फ़ वही जो आप या एजेंट माँगें, जैसे आपकी अपनी मशीन पर SearXNG के ज़रिए वेब सर्च, और पहली बार के डाउनलोड। /airgapped on यह सब बंद कर देता है।

यह कौन-सा मॉडल चलाता है?

NVIDIA के 4-बिट NVFP4 फ़ॉर्मैट में Qwen3.8-27B, SGLang पर DFlash2 ड्राफ़्टर के साथ, GB10 के लिए चुना और ट्यून किया हुआ। करीब 20 GB के वेट्स; चलते समय मशीन की लगभग 38 GB मेमोरी खाली रहती है।
