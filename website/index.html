Fast AI coding on your desk.
About 69% on SWE‑bench Verified.

68 of 100 SWE-bench Verified tasks, resolved offline on one DGX Spark, at about 47 tokens a second. A coding agent, a chat assistant and a desktop app, running entirely on your own GB10. No cloud. No account. No API bill. No telemetry. How it was measured

$ curl -fsSL https://github.com/dreamference/mightling/releases/latest/download/install.sh | bash
$ ling-admin server start      # downloads the model once (~20 GB), then serves it
$ cd ~/your-project && ling    # that's it

Works on the NVIDIA DGX Spark and every GB10 machine. The script verifies every download against the release's checksums and prints each sudo command before running it. Read it first if you like.

Mac and Linux clients

Your other computers use the GB10's model over the local network. On a Mac or another Linux machine, the same command above installs the ling client; it finds the GB10 by itself.

From 1.7.2 it also puts the desktop app in Applications on a Mac, ready to open (--no-app leaves it out).

Windows client preview

> irm https://github.com/dreamference/mightling/releases/latest/download/install.ps1 | iex

In PowerShell. It installs without administrator rights (from 1.7.2 the desktop app too), then Windows asks once to set up the agent's sandbox. Not signed yet, so Smart App Control must be off. Read the script.

New in 1.7: the desktop app on a Mac, Linux and Windows

Mightling 1.7.0's desktop app holds Ask and Work in one window. Work is a full workbench for agent sessions: a composer with files, skills and commands, a review pane to stage, revert and commit, worktrees, terminal tabs, and a file tree and file tabs beside the thread. On your other computers it is a client of your GB10, which it finds on the local network.

macOS preview

From 1.7.2, the install command puts Mightling in Applications beside ling, and it opens like any other app. Apple silicon and Intel, macOS 12 or later. ling update updates it.

Linux

On the GB10, mightling_1.7.0_arm64.deb installs the app, its launcher entry and the ling-app command, with the sandbox profile it needs:

$ sudo apt install ./mightling_1.7.0_arm64.deb

Then open it from the application menu, or with ling app. More.

Windows 11 preview

From 1.7.2, the PowerShell line installs the app as well, for you alone and without administrator rights, with a Start menu entry; Settings → Apps removes it; ling update updates it. Smart App Control must be off.

Other ways to install

The release page also carries the Mac dmg (Mightling-<version>-arm64-preview.dmg, or x64 for Intel) and the Windows installer (Mightling-Setup-<version>-x64.exe, or arm64). They are unsigned previews: downloaded in a browser, they are stopped the first time. Check each against the release's signed SHA256SUMS first.

  • macOS 15 and later: drag Mightling to Applications and open it once, then System Settings › Privacy & Security › Open Anyway. On macOS 14 and earlier, Control-click the app › Open.
  • Windows: SmartScreen › More info › Run anyway. Smart App Control must be off.

Also in 1.7.0: Night Shift can try a task several times and keep the best attempt (/night add --best-of N), one machine can run several Signal bridges, and a client chooses between two nodes on one network without losing the one it knows. Release notes and downloads.

How the ≈69% is estimated

100 tasks are a fifth of Verified, so the full-set figure is an estimate. A one-parameter item-response (Rasch) model is fitted on the per-task results of all 175 public Verified submissions: every task gets a difficulty and every system an ability. Mightling's ability is the one that explains 68 resolved on these 100 tasks; ≈69% is that ability's expected score on all 500 (a plain regression on the published scores agrees to within a point). To check it, every public submission was scored on these 100 tasks alone and its overall score predicted the same way: the error was 2.4 points (RMSE), and the band above is ±1.96 times that. Every number in the table is reproduced by scripts/swe_bench_compare.py from the public per-task data of SWE-bench/experiments.

The 100 tasks are spread across Verified's repositories in proportion to the full set, among the tasks whose test environment runs and validates on arm64 (the gold patch passes, an empty change fails). Published systems score 1.0 to 1.5 points lower on these 100 than on all 500, so the sample is not an easy one. It is not a leaderboard entry: those are graded by the SWE-bench team on their own infrastructure.

Your code never leaves your desk — and you can prove it

Cloud coding agents send your source code to someone else's servers. Mightling sends it nowhere: the model runs on your GB10, and nothing in Mightling phones home. No usage analytics, no metrics, no sign-in, no "anonymous" crash reports. That makes it usable for code you're not allowed to upload: client work, regulated data, unreleased products.

One command runs a real Mightling session under strace and lists every network connection it made:

$ ling-admin audit egress
✔ Egress audit: pass
Network destinations:
   127.0.0.1:8000     29x  model server
   127.0.0.1:8767      1x  Gmail search service
DNS queries: none
Networked git commands: none

Everything stayed on 127.0.0.1. Not one DNS lookup.

Need a hard guarantee?

Type /airgapped on and every command the agent runs gets an empty network namespace from the Linux kernel. It isn't a polite request to the model: there is simply no network to reach. Full Access, which would bypass the sandbox, is refused at the same time.

What can leave, and when

Only what you or the agent asks for: a web search (through a private SearXNG on your own machine), a page fetch, a read-only request to a Google account you connected, or an update check. At /airgapped on, none of it.

FAQ

Do I need a GB10?

Yes, to run the model. Your other computers use it as clients: Linux (Arm or x86) and macOS with the same install command, Windows (Arm or x86, preview) with the PowerShell line.

I installed Puffin. Is this it?

Yes: Puffin was renamed Mightling in 1.5. Run puffin update once, then puffin one last time. It moves your sessions, settings and links over, and from then on the command is ling.

Is it really free?

Yes. Mightling is open source under the AGPL, and the model's weights are free. Your only running cost is the electricity.

What do I need besides the machine?

The OS it ships with (DGX OS 7, or Ubuntu 24.04 where the vendor offers it), Docker with the NVIDIA Container Toolkit, Python 3 and Git. On plain Ubuntu, ling-admin host check tells you what's missing.

Does anything ever reach the internet?

Only what you or the agent asks for, such as a web search through SearXNG on your own machine, and the first-time downloads. /airgapped on turns all of it off.

Which model does it run?

Qwen3.8-27B in NVIDIA's 4-bit NVFP4 format, served by SGLang with a DFlash2 drafter, chosen and tuned for the GB10. About 20 GB of weights; roughly 38 GB of the machine's memory stays free while it serves.
