# Mightling Technical Specification

> - **Version:** 1.5.1 (`dreamference.__version__`). Release `v1.5.1` was published on 2026-10-08 from `480b10a`, the first under the name Mightling and the first signed one; `v1.4.0` (2026-10-06) and `v1.4.1` (2026-10-07) were Puffin's, and 1.4.2 and 1.5.0 were prepared but never published
> - **Target Hardware:** NVIDIA GB10 (Blackwell SM121, 128 GB unified memory)
> - **Deployment Model:** single node, with the model, the code and the sessions on the machine. Not air-gapped by default: web search, page fetch and Gmail use the internet unless `/airgapped on` ([MIGHTLING_AIRGAPPED](./DREAMFERENCE_MIGHTLING_AIRGAPPED.md)); a GB10 offered to the local network with `ling-admin node enable` serves clients that find it over mDNS ([MIGHTLING_NODE](./DREAMFERENCE_MIGHTLING_NODE.md), Parts 1–3 built in part; two GB10s paired on 2026-10-08, §18.10)
> - **License:** AGPL-3.0-or-later
> - **Specs last reconciled with the code:** 2026-09-28; the descriptive specs were re-checked against the parser, the model registry and the source tree on 2026-10-01, and CLI, CODEBASE, ARCHITECTURE, CONTEXT and DOCKER again on 2026-10-02 (at `cebd6db`) for `swe-bench`, `audit egress`, `node` and the three packages behind them. On 2026-10-03 (at `3624947`) a pass covered what changed that day: the diffusion sidecar switched off (ARCHITECTURE, INFERENCE, DOCKER, CODEBASE, SETUP, NODE, CLI), the `/airgapped` levels, the AppArmor profile for `bwrap` loaded and verified (SETUP, NODE, CLI), the `ling-admin` command list walked from the parser (CLI, AGENTS.md) and the twelve packages; specs being rewritten in parallel that night (APPS, DESKTOP, FLEET, CONTEXT_BUDGET, PYTHON_QUALITY, PROMPT §6/§13, SWE_BENCH §13) were left to them. On 2026-10-09 (at `95e4ee3`) MODELS, INFERENCE, DOCKER, CODEBASE, ARCHITECTURE, SETUP, CLI, AGENTS, CONTEXT, ONYX and MIGHTLING_CODEX were checked against the code again (one model on SGLang, the Electron app, `ling web`, the messengers, fleet provisioning, 23 patches), and the status lines of APPS, CHAT, DESKTOP, FLEET, GOA, PDF_SEARCH, PREFIX_CACHE, CONTEXT_BUDGET, the release notes, RELEASE_SIGNING, RENAME and the security review were brought up to date; MIGHTLING_ASK was left to its own update that night

This directory holds the specification, split into focused documents. This page is the index.

**Where the old monolith went:** earlier versions of this file also carried the whole pre-split specification, about 900 lines, below the index. That copy had drifted from the code on nearly every point (default agent, CLI commands, models, recipes), and it duplicated the modular documents. It was removed on 2026-09-28; it is in git history if needed.

## ⚠️ Known defects recorded in these specs

The reconciliation on 2026-09-28 found these places where the **code** was wrong or unsafe. Most were fixed on 2026-09-29, and the individual specs now describe the fixed behaviour, each with a one-line note of what it replaced.

### Accepted by design

| Where | Behaviour | Why it stays | Spec |
|---|---|---|---|
| Model server on `0.0.0.0:8000` | Listens on every interface with no API key, so any machine on the LAN can send it prompts | Mightling assumes the local network is trusted (decided 2026-09-30). The server must answer on the Docker bridge for Onyx and OpenHands, and binding the bridge address alone would break every `localhost:8000` client. On an untrusted network the user blocks the port with a firewall rule (`docs/privacy.md`) | INFERENCE |
